# پل شخصی Chat وب موبوکام — آزمایشی

این افزونهٔ غیررسمی برای مرورگر شخصی مدیر است؛ روی VPS نصب نمی‌شود.
تضمین مصرف رایگان/نامحدود ندارد. محدودیت، مدل و شرایط حساب ChatGPT پابرجاست؛
صفحهٔ Chat وب ممکن است تغییر کند و افزونه به اصلاح نیاز داشته باشد.
کوکی/توکن خوانده یا به موبوکام منتقل نمی‌شود؛ ورود دستی در مرورگر خودتان است.

1. ZIP را در کامپیوتر خود استخراج کنید. در chrome://extensions یا
   edge://extensions، Developer mode و Load unpacked را بزنید و همین پوشه را
   انتخاب کنید. فقط ChatGPT مجوز اولیه دارد؛ دسترسی موبوکام اختیاری است.
2. در همان پروفایل مرورگر به https://chatgpt.com وارد شوید و حالت Chat و مدل
   مورد نظر را انتخاب کنید. Work/Codex را انتخاب نکنید. ورود/CAPTCHA/محدودیت
   حساب باید توسط خودتان حل شود؛ افزونه آن‌ها را دور نمی‌زند.
3. صفحهٔ /admin/posts سایت HTTPS موبوکام خود را باز کنید. از آیکن افزونه
   «اتصال همین سایت موبوکام» را بزنید و دسترسی همان دامنه را تأیید کنید.
   سپس صفحه را تازه کنید. هر افزونه فقط به یک سایت متصل می‌شود.
4. در فرم نوشته، «دستیار نوشتن»، روش «Chat وب · پل مرورگر شخصی» را انتخاب
   کنید. منبع/متن را وارد و اجرا کنید. تب تازهٔ ChatGPT در پس‌زمینه باز
   می‌شود؛ نیازی به رفتن به آن ندارید. فقط پاسخ همان تب خوانده می‌شود و تب
   پس از پایان/لغو بسته می‌شود. گفتگو ممکن است در تاریخچهٔ حساب شما بماند.
5. نتیجه پس از پاک‌سازی در فرم می‌آید. اگر فرم حین انتظار تغییر کند، اعمال
   نتیجه نیازمند کلیک شماست. بازگشت به متن قبلی موجود است. هیچ نوشته‌ای
   خودکار ذخیره/منتشر نمی‌شود؛ فرم را بازبینی و با مسیر معمول ذخیره کنید.

اگر نصب/ورود/رابط/سهمیه آماده نباشد، خطا نمایش داده می‌شود و به API پولی
یا اتصال Work برنمی‌گردیم. ارسال دقیقاً یک بار است؛ لغو یا timeout ممکن است
مصرف قبلی حساب را پس نگیرد. از اجرای دوبارهٔ کورکورانه خودداری کنید.
برای قطع اتصال، از popup افزونه استفاده کنید یا افزونه/مجوز دامنه را حذف کنید.

منبع همین ZIP در deploy/chat-web-bridge است. بسته‌بندی با ابزار موجود:

    node scripts/pack-package.mjs deploy/chat-web-bridge public/downloads/mobocom-chat-web-bridge.zip

این کار API تولید مدل را فراخوانی نمی‌کند. نتیجهٔ آزمون DOM ساختگی تضمین
اتصال واقعی حساب نیست؛ اپراتور یک درخواست آزمایشی با حساب خود بررسی کند.

## نسخهٔ۰.۲: تولید انبوه و تصویر

در صفحهٔ /admin/ai/production هم قابل اتصال است. پس از ارتقای فایل‌ها، افزونه
را Reload و دامنه را دوباره متصل کنید. پل برای هر تصویر تب تازهٔ Chat دارد؛
تنها پیکسل تصویر تازهٔ همان پاسخ با canvas خوانده می‌شود. خطای CORS/ورود/
سهمیه یا نبود ابزار تصویر متوقف می‌شود؛ endpoint مخفی یا API جایگزین ندارد.
کوکی منتقل نمی‌شود؛ سهمیهٔ حساب پابرجاست. راهنمای کامل: docs/AI-PRODUCTION-FA.md.

نسخهٔ۰.۳: روی همان پروفایلِ واردشده به ChatGPT نصب/Reload و صفحهٔ موبوکام
تازه شود. کادر قدیمی/جدید/textarea و دکمهٔ ارسال یکتا پشتیبانی می‌شوند؛
اگر Work فعال و کلید صریح Chat موجود باشد، Chat انتخاب می‌شود. در غیر
این صورت ارسال نمی‌شود. خطای ورود یا UI، تب تازهٔ متعلق به پل را نمایان
و باز نگه می‌دارد؛ ورود و حل محدودیت با خود کاربر است. هیچ کوکی، API
خصوصی، CAPTCHA یا درخواست تکراری استفاده نمی‌شود. تولید API استاندارد
از پنل جدا انتخاب می‌شود و به این افزونه وابسته نیست؛ تصویر Chat همچنان
به افزونه نیاز دارد. سهمیهٔ رایگان یا نامحدود تضمین نمی‌شود.

نسخهٔ ۰.۴ انتخاب شخصی چت متنی Gemini، Qwen و DeepSeek را اضافه می‌کند. تصویر فقط ChatGPT است؛ رابط و سهمیهٔ حساب تضمین نشده و سشن به سرور منتقل نمی‌شود. راهنمای تنظیم: docs/AI-ECONOMY-FA.md در مخزن. همان افزونه را ارتقا، دسترسی‌های جدید را بررسی و دوباره به پنل متصل کنید.
