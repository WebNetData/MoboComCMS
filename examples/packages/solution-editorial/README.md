# نمونهٔ بستهٔ پیکربندی مجله

فایل `manifest.json` را در ریشهٔ یک فایل ZIP قرار دهید و از مسیر معمول بسته‌ها نصب کنید. نصب به‌تنهایی تنظیمات سایت را تغییر نمی‌دهد. مدیر پیش‌نمایش را بررسی و به‌صورت جداگانه اعمال می‌کند؛ پیشنهاد `promo-banner` صرفاً اطلاع‌رسانی است و خودکار دریافت یا نصب نمی‌شود.

این بسته از ماژول‌های موجود مجله و ویرایشگر بلوکی استفاده می‌کند. حذف نصب یا لغو مجوز بسته، تنظیمات اعمال‌شده و داده‌های سایت را پاک یا به حالت قبل برنمی‌گرداند. اعمال تنظیمات تنها برای کلیدهایی که میزبان مجاز و معتبر می‌داند امکان‌پذیر است. این نمونه محتوا، نقش، قالب یا اطلاعات محرمانه را تغییر نمی‌دهد.
