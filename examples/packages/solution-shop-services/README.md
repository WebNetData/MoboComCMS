# فروشگاه و خدمات

این بسته فقط ماژول‌های نصب‌شدهٔ Store، Forms و In-store را پس از پیش‌نمایش
و تأیید صریح مدیر فعال می‌کند. کالا، مشتری، فرم، نقش، پرداخت یا محتوای نمونه
نمی‌سازد و تنظیمات موجود را بازنویسی نمی‌کند. انتقال وجه و ارسال پیام ندارد.

آرشیو را با فرمان موجود بسازید:

```text
npm run package:zip -- examples/packages/solution-shop-services
```

برای انتشار تجاری، محصول PLUGIN با همین شناسه در مخزن فعلی تعریف و همان ZIP
را منتشر کنید. مجوز بسته، مجوز افزونه‌های پولی دیگر نیست. مشتری باید نسخه‌ای
از موبوکام با پشتیبانی Solution Pack v1 داشته باشد؛ پس از نصب، بخش بررسی
پیکربندی را باز کند. حذف بسته تنظیمات و سوابق کسب‌وکار را حذف نمی‌کند.
