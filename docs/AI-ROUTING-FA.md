# انتخاب سرویس و مدل هوش مصنوعی برای هر بخش

در **مدیریت ← دستیار هوش مصنوعی ← تنظیمات** کارت «سرویس و مدل هر بخش» را
باز کنید. این تنظیمات به مجوز مدیریت تنظیمات نیاز دارند. تغییر هر کاربرد،
API و مدل سایر کاربردها را تغییر نمی‌دهد.

برای سناریوی پشتیبانی با Gemini و مدیریت با ChatGPT:

1. «پشتیبانی آنلاین کاربران» را انتخاب کنید؛ روش اتصال را «API و مدل مستقل»
   بگذارید. سرویس Gemini، نام مدل مجاز و کلید همین سرویس را وارد و ذخیره کنید.
2. «پیش‌فرض ابزارهای مدیریت» را انتخاب و روش اتصال را «حساب شخصی ChatGPT همان
   مدیر» بگذارید. حساب شخصی خودتان باید در کارت ChatGPT متصل، دارای مدل و فعال
   باشد؛ [راهنمای ورود](CHATGPT-ADMIN-FA.md).
3. سایر کاربردها را در صورت نیاز جدا تنظیم کنید. پس از ذخیره، «آزمایش کاربرد
   انتخاب‌شده» یک درخواست با همان تنظیمات می‌فرستد؛ سهمیه/هزینهٔ معمول مصرف می‌شود.

| کاربرد | رفتار انتخاب «پیش‌فرض» |
| --- | --- |
| پشتیبانی آنلاین، بهبود هوشمند پرامپت‌مستر | API عمومی سایت؛ حساب شخصی مدیر مصرف نمی‌شود |
| پیش‌فرض ابزارهای مدیریت | اتصال شخصی فعال همان مدیر؛ در غیر این صورت API عمومی سایت |
| مجله، محصولات، دیدگاه‌ها، انجمن، سئو، ویرایشگر و فرم صفحات/موزیک/فیلم و سریال/بازی/نرم‌افزار | تنظیم «پیش‌فرض ابزارهای مدیریت» |

«API و مدل مستقل» حتی با اتصال شخصی فعال مدیر از همان API استفاده می‌کند.
«حساب شخصی» فقط برای کاربردهای مدیریتی قابل انتخاب است؛ هر مدیر از حساب خودش
مصرف می‌کند. اگر اتصال آن مدیر فعال نباشد، خطا می‌گیرد و API پولی جایگزین نمی‌شود.
انتخاب مستقل API هم هنگام خطا به سرویس دیگری نمی‌رود.

کلید را هنگام تغییر مدل خالی بگذارید تا حفظ شود. تغییر سرویس یا نشانی API،
کلید مقصد قبلی را حذف می‌کند؛ کلید مناسب مقصد تازه را وارد کنید. حذف عمدی با
«پاک‌کردن کلید ذخیره‌شده» انجام می‌شود. رفتن به حالت پیش‌فرض/شخصی، تنظیمات API
مستقل قبلی را برای انتخاب دوباره نگه می‌دارد؛ آن حالت از کلید نگه‌داشته‌شده
استفاده نمی‌کند. کلیدها در پاسخ مرورگر و گزارش مدیریت نمایش داده نمی‌شوند.

برای OpenAI API می‌توانید سرویس «سازگار با OpenAI» را با نشانی رسمی
`https://api.openai.com/v1` و مدل دارای دسترسی حسابتان تنظیم کنید. این مسیر،
API با صورتحساب خودش است؛ مصرف پلن ChatGPT فقط با گزینهٔ اتصال شخصی انجام می‌شود.
نشانی سفارشی باید متعلق به سرویس مورد اعتماد خودتان باشد.

با قطع یا غیرفعال‌کردن اتصال شخصی، کاربردهایی که صریحاً «حساب شخصی» انتخاب
کرده‌اند تا تغییر روش اتصال یا ورود مجدد خطا می‌دهند. برای استفاده از API، روش
همان کاربرد یا پیش‌فرض مدیریت را صریحاً عوض کنید. کاربردهای مستقل عمومی به کار
خود ادامه می‌دهند. انتخاب سرویس، مجوز بخش‌ها یا محدودیت دستیار پشتیبانی به
موبوکام را تغییر نمی‌دهد. مدل‌ها، دسترسی و سقف مصرف تابع سرویس انتخابی‌اند.

بدون تنظیم جدید، رفتار قبلی سایت حفظ می‌شود. مهاجرت دیتابیس لازم نیست. برای
بازگشت، کاربردها را روی پیش‌فرض بگذارید و در صورت نیاز اتصال شخصی را قطع کنید؛
این کار محتوا و تاریخچهٔ کاربران را پاک نمی‌کند.
