# هوش مصنوعی کم‌هزینه و اتصال شخصی چت

در «هوش مصنوعی ← تنظیمات»، اتصال‌های خودتان را تنظیم کنید. برای هر کاربرد
می‌توانید API، ChatGPT شخصی مدیریت یا سرویس «انتخاب خودکار کم‌هزینه» را انتخاب
کنید. تولید انبوه انتخاب مستقل دارد؛ اتصال دستیار مدیریت تغییر نمی‌کند.

در «انتخاب هوشمند منابع کم‌هزینه» سیاست را فعال، منابع مجاز را انتخاب و ترتیب
اولویت و حداکثر تلاش را ذخیره کنید. این سیاست کلید تازه نمی‌سازد یا جمع‌آوری
نمی‌کند؛ کلیدهای رمزگذاری‌شدهٔ موجود و مجموعهٔ کلیدهای خودتان استفاده می‌شوند.
اتصال هر سرویس ابتدا از پیش‌فرض سایت، سپس اولین کاربرد صریح آن سرویس، سپس مجموعهٔ
کلیدهای فعال انتخاب می‌شود. برای اتصال محلی بدون کلید، یک کاربرد API صریح بسازید.
اگر خودِ پیش‌فرض سایت را به کم‌هزینه تغییر می‌دهید، اتصال زیرمجموعه را در یک
کاربرد API یا مجموعهٔ کلیدها نگه دارید؛ فرم پیش‌فرض فقط یک اتصال نگه می‌دارد.

- OpenRouter: کلید خودتان را وارد کنید. سیاست فقط `openrouter/free` را فراخوانی
  می‌کند؛ این روتر مدل رایگان آماده را انتخاب می‌کند، با محدودیت سهمیهٔ سرویس.
- Ollama: نشانی قابل‌دسترسی از سرور با پسوند `/v1` و نام مدل نصب‌شده را وارد کنید.
  مدل `auto` اولین مدل محلی تأییدشده را انتخاب می‌کند. فهرست `/api/tags` هنگام نیاز
  حداکثر هر ۵ دقیقه تازه می‌شود؛ مدل ابری یا دارای مقصد remote پذیرفته نمی‌شود.
  دانلود مدل یا نصب سرویس خودکار انجام نمی‌شود. سخت‌افزار ظرفیت و هزینه دارد.
- OmniRoute: نشانی درگاه خودتان، معمولاً `http://localhost:20128/v1`، کلید بخش
  Endpoints و مدل دلخواه را تنظیم کنید. قبل از افزودن به سیاست کم‌هزینه، در خود
  درگاه اتصال‌های پولی و جایگزین پولی را غیرفعال و تأیید مربوط را در موبوکام ثبت
  کنید. موبوکام قیمت داخلی درگاه را مستقلاً تضمین نمی‌کند.

در Docker، `localhost` همان کانتینر است؛ برای درگاهی روی میزبان از نشانی قابل‌دسترسی
و حفاظت‌شده استفاده کنید. این تغییر کانتینر یا سرویس جدید نصب نمی‌کند.

وضعیت از پاسخ واقعی ثبت می‌شود. کلید ردشده یا سهمیهٔ تمام‌شده موقتاً کنار می‌رود
و اعلان داخل پنل مدیر ثبت می‌شود. فقط رد صریح کلید/سهمیه اجازهٔ رفتن به منبع بعدی
را می‌دهد. قطع ارتباط، پاسخ ناقص، لغو، رد محتوا و خطای سرور باعث تکرار خودکار
تولید نمی‌شوند. پس از تغییر سیاست یا مقصد، دستهٔ قبلی معتبر نیست؛ دستهٔ جدید بسازید.

برای چت وب، همان افزونهٔ پل را به ۰.۴ ارتقا دهید، دسترسی دامنه‌های جدید را بررسی
کنید، دوباره به سایت متصل شوید و پنل را تازه کنید. در تولید متن، ChatGPT، Gemini،
Qwen یا DeepSeek را انتخاب کنید و در همان پروفایل مرورگر وارد حساب خودتان باشید.
تصویر فعلاً فقط ChatGPT است. سشن و کوکی به سرور منتقل نمی‌شود؛ تنها تب تازهٔ ساخته‌شده
توسط پل استفاده می‌شود. رابط تغییرکرده، نیاز به ورود و چالش امنیتی باعث توقف و
نمایش تب می‌شوند. بررسی کنترل‌شدهٔ مرورگر جای تأیید حساب واقعی را نمی‌گیرد.

هیچ سرویس ابری، چت وب یا API رایگان تضمین نامحدودبودن، سرعت یا دسترسی دائمی ندارد.
این مسیر کلید دیگران، ساخت حساب انبوه یا دورزدن محدودیت را شامل نمی‌شود.

مرجع اتصال‌ها: [OmniRoute](https://github.com/cheaper-inference/OmniRoute)،
[مدل‌های رایگان OpenRouter](https://openrouter.ai/docs/guides/routing/model-variants/free)،
[رابط سازگار Ollama](https://docs.ollama.com/api/openai-compatibility).

برای بازگشت: دسته‌ها را متوقف کنید، سیاست کم‌هزینه را غیرفعال و کاربرد را به
API یا چت قبلی برگردانید. حذف داده یا مهاجرت جدیدی لازم نیست.
