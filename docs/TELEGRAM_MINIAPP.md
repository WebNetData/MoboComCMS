# مینی‌اپ تلگرام موبوکام

مینی‌اپ از همان حساب، مجوزها، محتوا، خریدها و تنظیمات سایت استفاده می‌کند. حساب جدا یا نسخهٔ دیگری از فروشگاه ساخته نشده است.

## راه‌اندازی

1. سایت را روی دامنهٔ عمومی با HTTPS معتبر راه‌اندازی کنید. آدرس شروع مینی‌اپ `https://YOUR-DOMAIN/miniapp` است؛ به نصب برنامهٔ دوم روی سرور نیاز ندارد.
2. در پنل مدیریت، بخش تلگرام (`/admin/telegram`)، ربات فعلی، نام کاربری و تنظیمات اتصال را تکمیل کنید. توکن ربات را فقط در تنظیمات محرمانهٔ موجود نگه دارید؛ داخل صفحه، کد مرورگر یا لینک قرار ندهید.
3. در BotFather، برای همان ربات آدرس Main Mini App یا Menu Button را روی مسیر بالا تنظیم کنید. تنظیم دامنه و ظاهر شروع برنامه نیز از تنظیمات همان ربات انجام می‌شود.
4. برنامه را از ربات روی تلگرام واقعی باز کنید. حساب باید با همان شناسهٔ موبوکام، موجودی و خریدهای سایت نمایش داده شود. پیش از اتصال، حساب موجود را از مسیر فعلی اتصال تلگرام در تنظیمات حساب به ربات پیوند دهید؛ ورود با اطلاعات تأییدنشده، شناسهٔ دلخواه یا صرفاً نام کاربری تلگرام ممکن نیست.
5. ورود مرورگر عادی هم پشتیبانی می‌شود: با حساب سایت وارد شوید و `/miniapp` را باز کنید. این روش برای بررسی ظاهر و عملکرد محلی است و جای تست روی تلگرام واقعی را نمی‌گیرد.

## صفحه‌ها

| مسیر | کارکرد |
| --- | --- |
| `/miniapp` | معرفی سرویس‌ها، موجودی حساب، دسترسی سریع و بخش‌های مشترک سایت |
| `/miniapp/explore` | جست‌وجوی بخش‌ها، محصولات و فیلتر تازه‌های موسیقی، سینما، بازی، نرم‌افزار و انجمن |
| `/miniapp/library` | کتابخانهٔ مشترک، علاقه‌مندی‌ها، پرامپت‌ها و دسترسی به کالکشن‌ها |
| `/miniapp/account` | پروفایل، سفارش‌ها، پرداخت‌ها، خدمات، پشتیبانی و تنظیمات حساب |
| `/miniapp/orders` و `/miniapp/orders/ID` | تاریخچه و جزئیات سفارش، وضعیت و دانلودهای مجاز با همان سرویس فروشگاه |
| `/miniapp/purchases` | خریدهای فایل و محتوا با همان سرویس خریدهای حساب |
| `/miniapp/wallet` | موجودی، گردش حساب و افزایش موجودی از مسیر پرداخت فعلی |
| `/miniapp/payments` | فاکتورهای حساب و وضعیت پرداخت/تحویل |
| `/miniapp/support` | تیکت‌های همان حساب |
| `/miniapp/notifications` | اعلان‌های همان حساب |
| `/miniapp/plans` و `/miniapp/subscriptions/ID` | امکانات موجود VPN، فقط در صورت فعال‌بودن ماژول و مجازبودن کاربر |

جزئیات تخصصی محتوا، پخش، خرید، ویرایش پروفایل، ساخت کالکشن و دیگر ابزارهای کامل به صفحهٔ اصلی همان قابلیت در سایت پیوند دارند. این صفحه‌ها بازنویسی نشده‌اند؛ دسترسی، قیمت نهایی گروه کاربری و اجرای عملیات را سرویس اصلی دوباره بررسی می‌کند. همهٔ آن‌ها فعلاً صفحهٔ اختصاصی زیر `/miniapp` ندارند. گردش بین این صفحه‌ها باید روی کلاینت هدف تلگرام نیز آزمایش شود؛ محدودیت iframe در Telegram Web با مرورگر عادی یکسان نیست.

## مدیریت محتوا و ظاهر

- نام، نشان، رنگ‌ها، تم روشن و تیره از تنظیمات فعلی سایت می‌آیند.
- نمایش بخش‌های محتوایی صفحهٔ اول از گزینهٔ نمایش در مینی‌اپ در Site Studio کنترل می‌شود.
- فهرست کشف از ماژول‌های فعال و سیاست فعلی دسترسی و نگهداری ساخته می‌شود. بخش خاموش یا محدود به گروه، از معرفی عمومی حذف می‌شود؛ معرفی عمومی، کاتالوگ خصوصی گروه‌ها نیست.
- عدد قیمت در معرفی محصولات، قیمت عمومی است. قیمت نهایی، تخفیف VIP و گروه‌های کاربری در صفحهٔ محصول و Checkout فعلی محاسبه می‌شود.
- پروفایل و تصویر، علاقه‌مندی‌ها، خریدها و کالکشن‌ها همان داده‌های حساب سایت‌اند. کتابخانه هنگام بازگشت به برنامه و رویداد همگام‌سازی موجود، دوباره اطلاعات معتبر سرور را می‌خواند.

## آزمایش و انتشار

پیش از انتشار، ورود واقعی از ربات، همگام‌بودن حساب، دکمهٔ بازگشت، تم‌ها، پخش، دریافت فایل و برگشت از درگاه را روی Android/iOS/Desktop و Telegram Web بررسی کنید. تست‌های محلی، ارسال واقعی ربات، پرداخت واقعی یا پذیرش یک انتشار توسط تلگرام را تأیید نمی‌کنند.

ادامهٔ توسعه و شواهد اجراشده: [یادداشت مهندسی](agent/handoffs/TELEGRAM_MINIAPP.md). مبنای اتصال کلاینت، [مستندات رسمی Mini Apps](https://core.telegram.org/bots/webapps) است.
