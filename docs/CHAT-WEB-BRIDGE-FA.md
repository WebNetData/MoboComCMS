# نوشتن با Chat وب از داخل پنل

در فرم نوشتهٔ مجله، «دستیار نوشتن» را باز و روش «Chat وب · پل مرورگر شخصی»
را انتخاب کنید. ZIP افزونه و راهنما همان‌جا قابل دریافت است. دستور نصب کامل
در [منبع افزونه](../deploy/chat-web-bridge/README-FA.md) آمده است.

افزونه در Chrome/Edge کامپیوتر مدیر و همان پروفایل حساب ChatGPT نصب می‌شود؛
نه روی VPS. پس از ورود دستی به ChatGPT و انتخاب Chat، افزونه را از تب
`/admin/posts` به دامنهٔ HTTPS موبوکام خود متصل و صفحه را تازه کنید.
درخواست از پنل اجرا، تب تازهٔ Chat وب فعال و پاسخ همان درخواست
به فرم برگردانده می‌شود. نتیجه قبل از ذخیره پاک‌سازی می‌شود و بازگشت به متن
قبلی وجود دارد. تغییر فرم حین انتظار مانع جایگزینی خودکار متن شما می‌شود.

این پل **غیررسمی و آزمایشی** است؛ API رسمی مدل، Work یا Codex را صدا نمی‌زند،
اما تضمین رایگان/نامحدود بودن استفاده ندارد. مدل و حالت Chat را خودتان در
حساب انتخاب و مصرف را همان‌جا بررسی کنید. تغییر UI، خروج حساب، CAPTCHA و
محدودیت ممکن است کار را متوقف کنند. پل آن‌ها را دور نمی‌زند و به سرویس
پولی برنمی‌گردد؛ درخواست خودکار تکرار نمی‌شود.

کوکی/توکن حساب استخراج یا به سرور منتقل نمی‌شود. تنها متن درخواست به حساب
ChatGPT فرستاده و پاسخ همان تب خوانده می‌شود؛ متن ممکن است در تاریخچهٔ حساب
بماند. این قابلیت مخصوص فرم نوشتهٔ مدیر است و حساب را در اختیار کاربران
پشتیبانی یا سایر مدیران قرار نمی‌دهد. افزونه فقط یک درخواست فعال دارد.
قطع اتصال/حذف افزونه یا مجوز دامنه جلوی درخواست‌های بعدی را می‌گیرد.

این مسیر فقط پیشنهاد را وارد فرم می‌کند؛ ذخیره/انتشار همان مسیر معمول و
مجوزهای فعلی مجله را دارد. خاموش‌کردن ماژول، حذف افزونه یا بازگشت کد داده‌های
ذخیره‌شده را حذف نمی‌کند. افزونه را تنها از انتشار مورد اعتماد نصب کنید.

پشتیبانی رسمی ابزار در ChatGPT با این DOM bridge تفاوت دارد:
[GPT Actions](https://developers.openai.com/api/docs/actions/introduction).
آزمون صفحهٔ ساختگی به معنی آزمایش حساب واقعی شما نیست؛ بعد از نصب، یک
درخواست کوچک با حساب خود و حالت Chat بررسی کنید.

برای تولید انبوه از پل ۰.۵ استفاده کنید: فایل‌های افزونه را جایگزین، در مدیریت
افزونه‌ها Reload، سپس اتصال سایت و تازه‌کردن پنل را انجام دهید. هر مطلب یک گفتگو
دارد و برای تصویر شاخص و هر تصویر داخلی یک درخواست جدا در همان گفتگو ارسال
می‌شود. «ادامه و بازیابی همین مرحله» به‌جای ارسال دوباره، پاسخ همان مرحله را
می‌خواند؛ «گفتگوی تازه» انتخاب جداگانه با احتمال تکرار مصرف است. بازیابی فقط در
همان تب و session، حداکثر ۲۰ دقیقه است؛ گفتگوهای قدیمی نسخهٔ قبل وارد نمی‌شوند.
خطای CORS تصویر یا نبود ابزار تصویر، مسیر مخفی یا API جایگزین ندارد.
