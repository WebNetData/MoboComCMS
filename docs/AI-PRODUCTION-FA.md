# تولید انبوهٔ محتوا و تصویر با Chat وب

مسیر **هوش مصنوعی ← تولید انبوه محتوا و تصویر** (`/admin/ai/production`)
از دستیار مدیریت جداست. اتصال فعلی دستیار/مهندسی تغییر نمی‌کند. این صفحه
از روش صریح انتخاب‌شدهٔ همان دسته استفاده می‌کند: Chat وب یا API استاندارد. هیچ خطایی به مسیر دیگر منتقل نمی‌شود.
قابلیت، سهمیه، مدل و محدودیت تولید تصویر حساب ChatGPT همچنان برقرار است؛
این اتصال تضمین رایگان یا نامحدود بودن مصرف نیست.

## نصب و آماده‌سازی

مهاجرت افزایشی `20270224120000_ai_production` با مسیر معمول
`npm run deploy:migrate` اجرا شود. داده‌های قدیمی پاک نمی‌شوند.
افزونهٔ پل را از همین صفحه دریافت، استخراج و در Chrome/Edge شخصی با
Developer mode / Load unpacked نصب یا به نسخهٔ۰.۳ ارتقا دهید. سپس افزونه
را باز، همین دامنه را متصل و صفحه را تازه کنید. در همان پروفایل به ChatGPT
وارد و حالت **Chat** و مدل دارای ابزار تصویر را انتخاب کنید. افزونه روی VPS
نصب نمی‌شود؛ کوکی/توکن استخراج یا به موبوکام فرستاده نمی‌شود.

## انتخاب سرویس و مدل

برای متن و تصویر روش مستقل انتخاب کنید. Chat وب به افزونهٔ۰.۳ و مرورگر
شخصی نیاز دارد؛ API متن می‌تواند بدون افزونه کار کند، به‌شرط خاموش‌بودن
تصاویر یا انتخاب API تصویر. روش دستهٔ ذخیره‌شده عوض نمی‌شود؛ دسته‌های قبلی
همچنان Chat وب‌اند. برای مسیر متفاوت دستهٔ تازه بسازید.

Qwen و DeepSeek به فهرست سرویس‌های AI اضافه شده‌اند. کلید را در تنظیم
پیش‌فرض، کاربرد «تولید انبوه · API متن» یا مجموعهٔ کلیدهای فعال همان سرویس
ثبت کنید؛ صفحهٔ تولید فقط سرویس‌های آماده را نمایش می‌دهد. سپس سرویس و
شناسهٔ مدل را برای دسته انتخاب و مصرف را تأیید کنید. انتخاب مدل دلخواه
و استفاده از سرویس‌های مجموعهٔ کلیدها به مجوز settings.manage نیاز دارد؛
مدیر یک بخش فقط از سرویس و مدل تعیین‌شدهٔ کاربرد تولید استفاده می‌کند. کلید در دسته یا
مرورگر ذخیره نمی‌شود. مسیر، کلیدهای سالم، اعلان و محدودیت‌های قبلی مشترک‌اند؛
دستیار مدیریت و Codex تغییر نمی‌کنند. تغییر مقصد سرویس، دستهٔ قدیمی را
متوقف می‌کند تا به مقصد تازه بدون انتخاب شما مصرف نشود.

Qwen پیش‌فرض از API سنگاپور و مدل qwen3.7-plus استفاده می‌کند؛ برای منطقه
یا دامنهٔ اختصاصی دیگر، گزینهٔ سفارشی را با مقصد و کلید همان منطقه بسازید.
DeepSeek پیش‌فرض deepseek-flash است. سهمیه و هزینهٔ API مستقل از رایگان‌بودن
چت وب است. برای مدل محلی Qwen/DeepSeek، سرویس سازگار با OpenAI را روی
میزبان خودتان راه‌اندازی و نشانی قابل دسترس از سرور موبوکام را تنظیم کنید؛
localhost داخل Docker خود کانتینر است. مدل محلی سهمیهٔ تجاری ندارد اما
به RAM، توان و هزینهٔ میزبان محدود است؛ نصب یا دانلود مدل خودکار انجام نمی‌شود.

برای API تصویر، کاربرد «تولید انبوه · API تصویر» را صریحاً به سرویس سفارشی
با مدل تصویر سازگار و خروجی b64_json متصل کنید. درخواست POST به
images/generations یک تصویر می‌خواهد؛ پاسخ باید فقط یک PNG/JPEG/WebP
base64 با اندازهٔ محدود باشد. URL برگشتی دانلود نمی‌شود. DeepSeek متنی
تصویر تولید نمی‌کند؛ API بومی تصویر Qwen هم پروتکل متفاوت دارد و این
آداپتر آن را ادعا نمی‌کند. می‌توانید متن را از Qwen و تصویر را از Chat وب
بگیرید، یا هر دو را API انتخاب کنید. حالت دوم مرورگر Chat لازم ندارد؛
صفحهٔ تولید برای ارسال مراحل بعدی باز بماند.

[اسناد Qwen و سهمیه](https://www.alibabacloud.com/help/en/model-studio/new-free-quota)،
[API استاندارد Qwen](https://www.alibabacloud.com/help/en/model-studio/compatibility-of-openai-with-dashscope)،
[مدل و هزینهٔ DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/).

## دستهٔ تولید

نوع را انتخاب کنید: مطلب مجله، محصول فروشگاه یا صفحه. فقط مجوز همان بخش
اجازهٔ تولید/ثبت می‌دهد؛ هر مدیر فقط دسته‌های خودش را می‌بیند.
تا۵۰ موضوع وارد کنید، هر خط یک مورد. اطلاعات قطعی مشترک و اطلاعات هر ردیف،
دسته‌بندی‌ها (اولی اصلی)، طول، لحن، کلمات کلیدی و دستور اختصاصی قابل تنظیم‌اند.
محصول هر خط: `نام | اطلاعات قطعی | قیمت دقیق | موجودی`؛ قیمت مثبت و
موجودی نامنفی را خودتان وارد کنید. ارز، نوع فیزیکی/مجازی و مشخصات فنی JSON
مشترک را مشخص کنید. فیلدهای الزامی دسته قبل از تولید بررسی می‌شوند؛ ویژگی،
قیمت یا موجودی از مدل گرفته نمی‌شود. دستهٔ نامتناسب یا دادهٔ ناقص رد می‌شود.

تصویر شاخص و۰ تا۳ تصویر داخل متن با سبک و نسبت دلخواه قابل انتخاب‌اند.
هر تصویر یک درخواست مستقل دارد. عکس تولیدشده «تصویرسازی با هوش مصنوعی»
است و مدرک عکس واقعی محصول نیست. alt از عنوان/تیتر و caption شفاف ساخته
می‌شود. فایل در سایت به WebP تبدیل و در همان کتابخانهٔ رسانه ثبت می‌شود.
مطلب/محصول تصویر اصلی را در فیلد خود دارند؛ صفحه تصویر اصلی را در ابتدای
بدنه به‌صورت بلوک تصویر می‌گیرد. تصاویر داخلی کنار بخش‌های متن قرار می‌گیرند.

## اجرا و ادامه

«ثبت دسته» سهمیه مصرف نمی‌کند. «شروع یا ادامه» مراحل متن و تصویر را
تک‌به‌تک اجرا می‌کند. تب تازهٔ Chat در پس‌زمینه باز و پس از دریافت بسته
می‌شود؛ نیازی به رفتن به آن ندارید. مرورگر/افزونه و صفحه باید باز بمانند؛
اجرای بی‌نیاز از مرورگر روی سرور ادعا نمی‌شود. درخواست‌ها و تصاویر ممکن
است در تاریخچهٔ حساب شما بمانند.

نتایج کامل‌شده روی سرور می‌مانند. پس از تازه‌سازی، دسته را از فهرست خود
باز کنید. خطا، قطع ارتباط، بستن تب یا سهمیهٔ تمام‌شده خودکار تکرار نمی‌شود؛
پس از پایان مهلت، وضعیت را تازه و برای همان ردیف «تلاش مجدد با انتخاب من»
را بزنید. اگر نتیجه نامطمئن است، ابتدا حساب را بررسی کنید تا هزینهٔ دوباره
نداشته باشید. توقف پاسخ دیررس را باطل می‌کند؛ موارد تکمیل‌شده حفظ می‌شوند.

ردیف آماده را بازبینی و به‌صورت پیش‌نویس ذخیره کنید؛ برای همهٔ ردیف‌های
آماده تأیید بازبینی لازم است. مطلب/صفحه DRAFT و محصول غیرفعال ثبت می‌شود؛
انتشار/فعال‌سازی از فرم معمول انجام می‌شود. ثبت همان ردیف دوباره محتوای
جدید نمی‌سازد. لغو دسته، خاموش‌کردن ماژول یا حذف افزونه اطلاعات ذخیره‌شده
و رسانه را پاک نمی‌کند. خطای هم‌زمان پس از واردکردن تصویر ممکن است فایل
را فقط در کتابخانه نگه دارد؛ بدون تأیید هیچ محتوا ذخیره نمی‌شود.

## محدودیت اتصال شخصی

پل۰.۳ پیش از گرفتن مرحله نسخه را بررسی می‌کند. کادر نوشتن و دکمهٔ ارسال
معتبر باید یکتا باشند؛ Work به Chat فقط با کنترل صریح Chat تغییر می‌کند.
اگر ورود یا دخالت دستی لازم باشد، تب متعلق به همان درخواست باز و نمایان
می‌ماند؛ بعد از ورود/انتخاب Chat در همان پروفایل، در موبوکام صریحاً تلاش
مجدد کنید. هنوز ارسال نشده را از درخواست نامطمئنِ پس از ارسال تفکیک کنید.
این پل آزمایشی و غیررسمی به DOM Chat وابسته است. ورود، CAPTCHA، سهمیه،
نبود ابزار تصویر یا تغییر رابط را باید خودتان بررسی کنید. افزونه فقط تصویر
نمایش‌داده‌شده در پاسخ تازهٔ خودش را با canvas می‌خواند؛ اگر مرورگر دسترسی
پیکسل را منع کند، فایل مخفی یا endpoint خصوصی دریافت نمی‌شود و مرحله خطا
می‌دهد. نتیجهٔ آزمون ساختگی، تأیید کارکرد حساب واقعی شما نیست.

دستیار/پشتیبانی/مهندسی از این حساب برای عملیات خودکار استفاده نمی‌کنند؛
مسیر Chat وب هیچ Work/Codex یا inference API را فراخوانی نمی‌کند؛
مسیر API فقط پس از انتخاب صریح و تأیید مصرف همان دسته فعال می‌شود. سیاست مصرف و انتخاب Chat را در حساب خود بررسی کنید.
[مستند رسمی تولید تصویر](https://learn.chatgpt.com/docs/image-generation).

بازگشت: تولید فعال را متوقف، پل را قطع و در صورت نیاز کد قبلی را برگردانید.
جدول‌های افزوده و داده‌هایشان را حذف نکنید. برای تغییرات این قابلیت، فایل‌ها
یا تگ ریلیز۱.۷.۹ بازنویسی نمی‌شوند.

پیش از بازگشت به کد قدیمی، دسته‌های API را متوقف/لغو و AI را غیرفعال کنید؛
نسخهٔ قدیمی روش جدید دسته را نمی‌شناسد. اگر Qwen/DeepSeek در تنظیمات ثبت
شده‌اند، کد قدیمی آن شناسه‌ها را نمی‌شناسد؛ بازگردانی تنظیمات AI از بکاپ
قبل از ارتقا تصمیم صریح اپراتور است، نه حذف خودکار داده. داده و کلیدهای
بکاپ‌شده حفظ شوند. برای استفادهٔ دوباره از قابلیت، کد جدید لازم است.

برای مدل‌های GPT Image، خروجی base64 پیش‌فرض است؛ پارامتر قدیمی
response_format ارسال نمی‌شود. WebP با کیفیت متوسط و فشرده‌سازی۸۵ انتخاب
می‌شود تا اندازه محدود بماند. سرویس سازگار دیگر باید b64_json را پشتیبانی
کند. نسبت تصویر API ممکن است با اندازهٔ استاندارد نزدیک بازگردد.
[مستند رسمی Images API](https://developers.openai.com/api/reference/resources/images/methods/generate).

اگر پروفایل Xray برای AI فعال است، قواعد دامنهٔ ابزار root باید به‌روز
باشد تا dashscope-intl.aliyuncs.com و api.deepseek.com مجاز شوند. آپدیت
وب به‌تنهایی ابزار root نصب‌شده را عوض نمی‌کند؛ اپراتور ابزار مورد اعتماد
Xray را از سورس مرورشدهٔ جدید ارتقا و تنظیم پروفایل را دوباره اعمال کند.
نسخهٔ پروتکل۲ پروکسی حفظ شده و مجوز سایر دامنه‌ها باز نمی‌شود. برای منطقهٔ
دیگر Qwen، مقصد سفارشی خارج از فهرست AI مستقیم می‌رود.
