# Track discovery

Evidence: track detail already has album tracks and more-from-artist lists; album detail already uses Recommendations' contextual ranker. Track detail lacks cross-artist genre discovery, and the private recommendation service does not support track seeds. Extend these owners rather than adding another engine or duplicating artist lists.

Add a bounded Recommendations adapter for published, due tracks by other artists with an exact shared genre after normalization. Query at most 180 candidates and display at most eight. Rank with the existing deterministic genre/freshness/ID rules, not mutable play counts. Rehydrate selected tracks with current publication filters and return only existing safe TrackCard data plus a reason; media sources remain behind the canonical playback API. Empty/missing genre yields no rail. Track favorites/views can contribute through the existing consent/Admin-gated private recommendation flow.

Public track detail uses the existing mu-panel/TrackList composition and player. Preserve hero, downloads, paywall, lyrics, album/artist lists, review controls and protected Music visuals. Explain the shared-genre reason in Persian/English. Add showRelatedTracks to existing music.portal.v1 and the current permission-guarded Music settings page. Default enabled; old clients omitting the new flag preserve its current value. The flag controls this public detail rail; the existing personal recommendation pause/consent controls still own private results. No new table, migration, identity, permission or route.

Acceptance: exact normalized genres, different artists, due-only candidates, deterministic ranking, bounded pool, no play-count influence, current-source hydration, empty/disabled rail, old-client setting preservation and consent-safe track seeds. Run focused domain/service checks, TypeScript/source/architecture/security, local PostgreSQL/API and browser checks with restored settings/fixtures, RTL dark/light mobile/desktop visual checks and clean-source PostgreSQL build. Preserve raw-media secrecy and existing player access checks.
