# بررسی یکدستی رابط کل سایت —۲۰۲۶-۱۱-۱۵

درخواست مالک: صفحات عمومی، حساب و پلتفرم/مدیریت بررسی شوند تا بخش بی‌استایل،
چیدمان شکسته یا کنترل نامرتب باقی نماند. محدوده، اصلاح عیب قابل مشاهده است؛
بازطراحی هویت موبوکام یا تغییر قراردادهای محصول درخواست نشده است.

Checkout: `.mobocom/sms-platform`؛ شاخه `fix/site-ui-consistency-2026-11-15`،
از main `aa20d05a` پس از ادغام PR478. کارهای سایر checkoutها حفظ می‌شوند.

## موجودی و ماتریس شواهد اولیه

موجودی منبع:۳۴۳ صفحهٔ ثابت شامل۲۰۳ Admin،۳۵ حساب و۱۰۵ مسیر دیگر؛ مسیرهای
پارامتری جدا هستند. تعداد مسیر، اثبات رندر صحیح یا دسترس‌پذیری نیست.
موجودی دقیق و تصاویر خصوصی در `var/site-ui-audit` نادیده‌گرفته‌شده نگهداری می‌شوند.

۱۶ نمای اولیهٔ کامل از درخواست/پروفایل حساب، فرم‌ها/خدمات/تنظیمات/خانهٔ Admin،
پیگیری تعمیر و جست‌وجو در۱۴۴۰ تیره و۳۹۰ روشن: scoped axe0 و overflow0.
این نمونه‌ها گواه کل سایت نیستند. تصاویر قبلی که هنوز skeleton بودند، خطای
سرور توسعه یا درخواست معلق داشتند، شاهد پذیرش محسوب نمی‌شوند.

## هدف و برش‌های اصلاح

- reuse: توکن‌های SDS/MoboCom، primitiveها و الگوهای فعلی حفظ شوند. سلسله‌مراتب
  عنوان/شرح/عملیات/فیلتر/داده و کنترل‌های حداقل۴۴ پیکسل در محل مربوط بررسی شود.
- change: فقط موارد تأییدشده در مرورگر و owner صحیح اصلاح شوند؛ جدول در ظرف
  اسکرول خودش بماند و صفحهٔ موبایل را عریض نکند. CSS مدیریت زیر `.admin-shell`
  و CSS حساب/ماژول در محدودهٔ خودش باشد؛ مخفی‌کردن overflow کل صفحه راه‌حل نیست.
- new: هیچ design system، تنظیم، هویت، مدل داده یا لایهٔ مشترک تازه لازم نیست.
- ترتیب: موجودی فقط‌خواندنی → عیب‌های مشترک کم‌خطر → عیب اختصاصی حوزه →
  مقایسهٔ قبل/بعد و چهار ترکیب پوسته/viewport برای قسمت تغییرکرده.

## قرارداد و پذیرش

مالکیت/مجوز/روابط/داده/ویرایشگر/API/مسیر/SEO/ماژول خاموش همان قرارداد موجود
است؛ تغییر کسب‌وکار یا schema در این کار کاربرد ندارد. هویت‌های مصنوعی و یک
فرم/درخواست آزمایشی فقط برای مشاهده ساخته شده‌اند؛ پیامک/ایمیل/پرداخت واقعی
انجام نمی‌شود. داده و عنوان واقعی مشتری برای مرتب‌سازی ظاهری بازنویسی نمی‌شود.

پذیرش هر اصلاح: تصویر واقعی قبل/بعد، کنترل بارگذاری/خالی/خطا/انتخاب/disabled
متناسب، RTL و متن ترکیبی، موبایل، هر دو پوسته، keyboard/focus و axe مربوط؛
React Doctor برای React تغییرکرده، TypeScript/import/architecture متناسب.
رگرسیون ورود از Admin به صفحهٔ عمومی باید نشان دهد CSS پنل به سایت نشت نمی‌کند.
بررسی PostgreSQL متصل برای داده/رفتار تغییرکرده لازم است؛ ادعای تغییرندادهٔ
مدل یا اجرای مجدد تست‌های قدیمی از این مرور ظاهری حاصل نمی‌شود.

rollback فقط بازگرداندن CSS/ارائهٔ همین برش است؛ دادهٔ تاریخی و تنظیمات حفظ
می‌شود. انتشار/PR/مرج/دیپلوی این برش هنوز انجام نشده است. گزارش نهایی باید
مسیرهای بررسی‌نشده، محدودیت تصاویر بیرونی مسدودشده و شکست‌های محیط را جدا کند.
