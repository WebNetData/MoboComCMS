# بررسی اتصال هوش مصنوعی و Gemini

تنظیمات دستیار در `/admin/ai` و مسیر شبکه در `/admin/server/proxy` قرار دارد.
آزمایش اتصال از تنظیمات **ذخیره‌شده** استفاده می‌کند؛ پس ابتدا تنظیمات را ذخیره کنید.

## سرور ایران و مسیر Xray

1. در پنل سرور، «پروکسی Xray» را باز کنید و وضعیت نصب و فعال بودن سرویس را ببینید.
2. یک پیکربندی معتبر ذخیره کنید، همان پیکربندی را برای کاربرد «هوش مصنوعی» انتخاب کنید
   و مسیرها را اعمال کنید. داشتن پیکربندی برای تلگرام به‌تنهایی هوش مصنوعی را از آن عبور نمی‌دهد.
3. به `/admin/ai` برگردید، Gemini و کلید مربوط به همان پروژه را ذخیره کنید و «آزمایش اتصال» را بزنید.
4. آزمایش عمومی Xray به‌تنهایی سلامت کلید، سهمیه یا دسترسی Gemini را ثابت نمی‌کند؛
   آزمایش دستیار درخواست واقعی به سرویس انتخاب‌شده می‌فرستد و ممکن است مصرف سهمیه داشته باشد.

اگر پنل دربارهٔ قدیمی بودن ابزار Xray هشدار داد، اپراتور باید طبق راهنمای نصب موجود،
ابزارهای روت را به‌روز کند؛ به‌روزرسانی کد سایت، فایل نصب‌شدهٔ روت را عوض نمی‌کند:

```bash
sudo bash /opt/mobocom/app/deploy/ubuntu/xray-install.sh
```

این دستور برای مسیر نصب پیش‌فرض است. تغییر مسیر نصب باید مطابق نصب واقعی باشد.
پس از به‌روزرسانی ابزار، انتخاب مسیر «هوش مصنوعی» را دوباره اعمال کنید.

## معنی خطاها

| پیام | بررسی بعدی |
| --- | --- |
| مسیر مستقیم | برای میزبان‌های مجاز، مسیر «هوش مصنوعی» را در پنل Xray انتخاب و اعمال کنید. |
| مسیر Xray، اتصال یا دریافت پاسخ کامل نشد | سرویس محلی، پیکربندی انتخاب‌شده، دسترسی سرور خروجی به Google و لاگ سرویس را بررسی کنید. |
| محدودیت جغرافیایی | سرویس IP خروجی را نپذیرفته است؛ این پیام اثبات نامعتبر بودن کلید نیست. محل و مجاز بودن IP خروجی را بررسی کنید. |
| کلید API نامعتبر | کلید Gemini همان پروژه را دوباره ذخیره کنید. |
| دسترسی رد شد، 403 | مجوز API، وضعیت پروژه و محدودیت‌های کلید را بررسی کنید. |
| سهمیه یا محدودیت درخواست، 429 | سهمیه، محدودیت درخواست و وضعیت پرداخت پروژه را بررسی کنید. |
| مدل پیدا نشد، 404 | نام مدل و دسترسی پروژه به آن را بررسی کنید؛ خالی بودن فیلد مدل از پیش‌فرض فعلی استفاده می‌کند. |
| بودجهٔ توکن تمام شد | پاسخ خالی لزوماً شکست شبکه نیست. بودجهٔ خروجی/تفکر مدل را بررسی کنید. |
| کلید قابل خواندن نیست | مقدار `PANEL_CREDENTIAL_KEY` قبلی را حفظ کنید؛ در صورت خراب بودن مقدار ذخیره‌شده، کلید اصلی را دوباره وارد کنید. |

در درخواست‌های کوتاه تا ۱۲۰۰ توکن، Gemini 2.5 Flash/Flash-Lite با تفکر خاموش فراخوانی
می‌شود تا بودجهٔ پاسخ صرفاً در تفکر مصرف نشود. درخواست‌های طولانی و مدل‌های دیگر
رفتار قبلی را دارند. به‌روزرسانی مدل‌های پیش‌فرض موضوع جداگانه است.

میزبان‌های Xray فهرست ثابت دارند؛ سرویس سفارشی خارج از این فهرست مستقیم متصل می‌شود.
هیچ خطای پروکسی باعث تکرار خودکار درخواست از مسیر مستقیم نمی‌شود.

کلید API، لینک محرمانهٔ Xray، فایل محیط یا هدر Authorization را در چت و Issue منتشر نکنید.
برای گزارش مشکل، متن خطای جدید و وضعیت مسیر مستقیم/Xray کافی است.

قرارداد توسعه، آزمون‌ها و محدودیت‌های تأیید: [ادامهٔ کار اتصال AI](agent/handoffs/AI_CONNECTION.md).
