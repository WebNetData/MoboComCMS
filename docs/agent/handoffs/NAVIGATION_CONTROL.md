## Owner and operating contract

- `/admin/studio?tab=design`: header/navigation and support footer trees; optional independent Explore/Account footer lists; automatic published-page link switch. `site.config.v1` retains its original flat format and gains optional IDs, children, icons and visibility. Existing per-theme Account defaults remain when the independent list is absent. Disabling independence restores inheritance; it does not delete content.
- `/admin/mega-menu`: Store, Magazine, Music, Cinema, Games, Software and Forum bars. Custom nested trees, root/subcategory menu-only title/icon/visibility/order overrides, home link, custom/automatic quick links, existing search/count/featured/promo controls. Quick links support individual visibility and ordering. The editor links to each canonical category manager.
- Existing category CRUD stays at `/admin/postcats`, `/admin/productcats`, `/admin/taxonomy?tax=software|games|music|music-language|cinema`, `/admin/forum`. IDs, parent validation, stored content and public addresses stay owned there. Menu-only names do not rename canonical categories. Removing a menu link never removes a category or post.
- `settings.manage` is required for site/section presentation. Section category permissions remain separate; `cms.posts` does not grant site settings or another section. A hidden menu is not an authorization rule. Forum automatic trees use `visibleCategories(await viewerFor(null))`, including group restrictions.
- Shared `SiteLink` trees allow five levels and 120 entries per list. IDs remain stable during editing; legacy entries get IDs only in the client draft until an explicit save. Icons are registered names or bounded text/emoji; absent means the previous automatic icon, empty string means none. HTML/SVG input is not accepted. Hidden ancestors and switched-off modules prune complete branches.
- Public header disclosure buttons are separate from ordinary links, with Escape/outside/focus dismissal. Default/MoboCom footers retain hierarchy; compact Clean/Orbital footers list descendants in their existing column compositions. Preserve the approved full-width footer and public layouts.
- Both Admin editors send `If-Match` revisions. Stale saves return 409, preserving the draft; refresh/reconcile before saving again. Legacy callers may omit the header for compatibility. Permission recheck, settings claim and strict audit share a serializable transaction. Audit failure rolls back the setting. No schema/migration change.
- Initial fetches and live previews cancel obsolete requests. This prevents a slow StrictMode initial response from replacing typed drafts. Editing is disabled during a save to avoid losing newer unsent changes. Section rendering reads the fresh document revision before reusing its 60-second category-tree cache; settings changes become visible on reload across separate handler/render instances. Canonical category edits can retain the existing brief category-cache delay.
- All category roots remain reachable, including those past the former twelve-root limit. Featured-content queries retain the previous twelve-root budget; later roots still have their links and subcategories. Long accepted custom IDs produce bounded stable presentation keys. A pending delete follows its item's identity when the list is reordered.
