## موجودی و یافته‌های تأییدشده

منبع شامل۳۴۳ صفحهٔ ثابت است:۲۰۳ Admin،۳۵ حساب و۱۰۵ مسیر دیگر. مسیرهای پویا
در این شمارش نیستند. موجودی نقش‌ها/مالک‌ها از source و دو mapper فقط‌خواندنی
است؛ source به‌تنهایی شاهد سلامت runtime نیست. Graphify موجود stale بود و
query با `Out-of-corpus graph source: src/app/admin/ai/CredentialPools.tsx`
رد شد؛ ادعای graph تازه نداریم. Serena manual و فعال‌سازی checkout انجام شد.

مرور اولیهٔ موبایل/روشن۱۹۴ مسیر Admin را طی کرد؛ بیرون‌زدگی افقی کل صفحه۰،
اما۲۱ صفحه خطای scoped axe داشتند (۱۴ صفحه کنتراست و۷ صفحه دسترسی به ناحیهٔ
اسکرول). سه نمونه هنوز درخواست معلق داشتند و یک خطای fetch در همان وضعیت بود؛
آن‌ها گذر موفق محسوب نمی‌شوند و در بازبینی نهایی قرار گرفتند.۹ composition
بزرگ‌تر AI/editor بعداً جدا بررسی می‌شوند؛ فعال‌بودن صفحهٔ یک ماژول خاموش
از صفحهٔ «این بخش غیرفعال است» استنباط نمی‌شود و ماژولی برای ممیزی فعال نشد.

مرور دوم۷۶ مسیر عمومی و۳۴ مسیر حساب را در۳۹۰ روشن بررسی کرد، با نمونه‌های
اصلی۱۴۴۰ تیره و۱۶ نمای جدا با scoped axe0. چهار صفحهٔ عمومی مشکل داشتند:
تقویم سینما، گروه‌های انجمن، صفحهٔ اصلی انجمن و بازی‌های برتر. دو capture
در انتظار CSS/session متوقف شدند و چند درخواست معلق به فهرست بررسی مجدد رفتند.
حالت ورود/رد دسترسی جای بررسی فرم داخلیِ حساب واردشده محسوب نمی‌شود.

## تغییرهای ارائه، در owner موجود

- `admin-tidy.css`: خوانایی برچسب/لینک‌های سینما/موزیک، تیکت/دیدگاه/دسته،
  فیلتر CRM، برچسب فاکتور، پیام خطای مگامنو، بازهٔ تحویل، شمارنده و عملیات
  taxonomy و لینک/فیلتر قالب‌ساز از توکن‌های خوانای موجود Admin پیروی می‌کند.
  کارت‌های غیرفعال profile-fields/sections با محوکردن کل متن نمایش داده نمی‌شوند؛
  برچسب غیرفعال حفظ است و کادر خط‌چین نشانهٔ تکمیلی است. focus جدول مشخص است.
- `automation.css`: برچسب recipe از accent متنی مدیریت استفاده می‌کند؛ متن
  وضعیت اجرا با رنگ معنایی و متن پوسته ترکیب می‌شود. اعداد و وضعیت‌ها عوض نشدند.
- wrapperهای جدول بسته‌های تبلیغ، تحویل، فورواردر، خبرنامه، اعلان‌ها، بهینه‌سازی
  و لایسنس‌های مخزن: نام قابل فهم و `tabIndex=0` روی همان ناحیهٔ اسکرول موجود؛
  اسکرول خود جدول باقی است و صفحه عریض نمی‌شود. هیچ DOM patch عمومی اضافه نشد.
- `admin/ai/Workspace` و CSS خودش: در موبایل دکمهٔ دستیار با آیکن موجود و نام
  دسترس‌پذیر به سرصفحه منتقل شد؛ دیگر روی پایین فرم شناور نمی‌ماند. ابزارها،
  مجوز، ماژول‌خاموش، dialog و lazy import همان owner قبلی هستند.
- `media-design.css`، `forum.css`، `games-portal.css`: فقط رنگ متن نامناسب روی
  سطح روشن برای برچسب VIP تقویم، نام تازه‌ترین عضو/وضعیت گروه و خلاصهٔ رتبه‌بندی
  اصلاح شد؛ hue و چیدمان نگه داشته شدند. لینک تصویر رتبه‌بندی در `GameV2`
  نام بازی را برای صفحه‌خوان دارد. تصویر تزئینی همچنان alt خالی است.

هیچ schema، دادهٔ کسب‌وکار، تنظیم، permission، API، URL، محتوای ذخیره‌شده،
هویت یا رفتار مالی عوض نشده است. این‌ها اصلاح ارائهٔ Core و owner ماژول موجودند؛
رجیستری/سیستم قالب یا افزونهٔ موازی ندارند. CSS مدیریت زیر `.admin-shell` است.

## شواهد واقعی تا این checkpoint

- Playwright نصب‌شده با Edge محلی روی Docker localhost3000؛ زبان fa-IR/manual،
  reduced motion، نقش مهمان و دو هویت مصنوعی Admin/customer. فقط درخواست‌های
  GET/HEAD محلی مجاز؛ ارسال واقعی provider، خرید و عملیات حساس انجام نشد.
- یک فرم/درخواست مصنوعی با عنوان بلند، reply و رسید ساخته شد تا نمونهٔ اصلی
  «ثبت دوباره»/پیام کارشناس/رسید در حساب دیده شود.۱۴۴۰ تیره و۳۹۰ روشنِ این
  کارت، همراه پروفایل، Forms/Services/Settings/Admin و جست‌وجو/پیگیری،۱۶ نمای
  scoped axe0/overflow0/errors0 داشتند؛ captureهای نهایی هم جدا ثبت می‌شوند.
- mapper فقط‌خواندنی تصاویر۱۵ Admin را مرور کرد؛ lead montageهای عمومی و
  مدیریت و تصاویر اصلی را دید. جدول عریضِ محصور، صفر فارسیِ نقطه‌مانند و checkbox
  بومی به‌خودی‌خود عیب فرض نشدند. پوشاندن فرم با دکمهٔ دستیار تأیید و اصلاح شد.
- نبود CSS در capture اول بازیابی رمز و ظاهر دو prompt به‌طور محدود بررسی شدند:
  دو بار بازیابی و یک login با CSS200/ظاهر سالم؛ پیگیری تعمیر دقیقاً یک prompt
  قابل مشاهده داشت. مورد تکرار نشد؛ تغییر محصول برای آن ادعاها انجام نشد.
- TypeScript با UID1000 و `--noEmit --incremental false`، source/import۳۰۰۹ فایل،
  architecture و هم‌خوانی رجیستری افزونه‌ها گذشتند. اولین tsc بدون خاموش‌کردن
  incremental فقط برای نوشتن tsbuildinfo متعلق به root خطای permission داد؛
  آن تلاش گذر موفق نبود، مالکیت فایل/مجوز آزمون تغییر نکرد.
- React Doctor0.9.17: هشت client مربوط به مدیریت۰ خطا/۳۸ هشدار و GameV2۰ خطا/۲
  هشدار؛ موارد قدیمی parse/complexity/fetch/index و JSX تکراری بازبینی شدند.
  تغییرهای این برش نام/تمرکز/ارائه هستند؛ suppression یا dependency upgrade ندارد.

دو اجرای موازی ابتدایی سرور توسعه را با compile/prefetch سنگین کردند؛ چند
`ERR_EMPTY_RESPONSE` و capture زمان بارگذاری پذیرفته نشد. helper به درخواست‌های
محلیِ کامل‌شده، CSS و زبان صریح وابسته شد و prefetch را متوقف کرد؛ بررسی‌ها
ترتیبی ادامه یافتند. این محدودیت محیط به‌عنوان ایراد ظاهری محصول گزارش نشد.
تصاویر بیرونی مسدودند؛ آیکن تصویر شکستهٔ بیرونی شاهد خراب‌بودن خود asset نیست.

## تکمیل و rollback

شواهد نهایی، پاک‌سازی و کامیت بعد از اجرای واقعی در ادامهٔ همین سند ثبت می‌شوند.
raw report/capture/کوکی و پشتیبان در `var/site-ui-audit` ignored و خصوصی‌اند؛
جزئیات مشتری و توکن رسید وارد Git نمی‌شوند. rollback فقط فایل‌های ارائهٔ این
برش است؛ DB و دادهٔ تاریخی تغییر نمی‌کند. Container/image/port/storage فعلی
حفظ می‌شود. انتشار/مرج/production deploy برای این درخواست انجام نشده است.

پروندهٔ واقعیِ سفارش، checkout/provider، همهٔ شناسه‌ها/تنظیمات/قالب‌های ممکن
با نمونه‌گیری ظاهری تأیید نمی‌شوند. مسیر اتصال خارجی بدون حساب/توکن واقعی
گواه end-to-end ندارد. پوشش دقیق نهایی و محدودیت‌های باقیمانده باید گزارش شوند.

## پذیرش نهایی و پاک‌سازی —۲۰۲۶-۱۱-۱۵

مرور واقعی به۳۴۰ مسیر از۳۴۳ مسیر ثابت رسید؛ سه مسیر اتصال خارجی
`/login/google`،`/login/telegram/callback`،`/telegram/connect` بدون حساب/توکن
واقعی فراخوانی نشدند. وضعیت ورود/عدم دسترسی/ماژول خاموش، پوشش محتوای داخلی
آن ماژول نیست. مسیرهای پویا فقط با نمونه‌های موجود بررسی شدند؛ همهٔ شناسه‌ها،
صفحه‌بندی‌ها، حالت‌های فرم و قالب‌های قابل نصب گواه عمومی ندارند.

تجمیع آخرین گزارش‌ها: 400 نمای یکتای دارای scoped axe0،
overflow0 و بدون خطای ثبت‌شده/درخواست معلق؛ 340 مسیر ثابت
در موبایل دارای همین شواهد است. معیار این عدد همان گزارش ignored coverage.json
است؛ تلاش‌های شکست‌خوردهٔ قبلی به‌جای گذر موفق شمرده نشده‌اند.
۴۸ نمای نهایی از۱۲ ترکیب صفحه در۱۴۴۰/۳۹۰ روشن/تیره همگی با scoped axe0،
overflow0، runtime errors0 و بدون درخواست معلق گذشتند. تصاویر واقعی نهایی
اتوماسیون، تقویم، مینی‌اپ و دستیار۳۲۰ نیز بازبینی شدند.

آزمون تعاملی در۳۹۰ روشن/تیره،۳۲۰ روشن و۱۴۴۰ تیره: جای دکمهٔ دستیار داخل
viewport و hit-test بدون پوشش، کلیک واقعی/open/Escape/بازگشت focus، منوی
موبایل و اسکرول افقی جدول با ArrowLeft گذشت. یک نسخهٔ میانی فقط با bounding box
قابل مشاهده تشخیص داده شده بود؛ hit-test نشان داد mobile-bar دکمه را می‌پوشاند.
لایهٔ دکمه فقط در header موبایل به لایهٔ موجود۷۰ منتقل شد و آزمون واقعی گذشت.
fullscreen builder که header متفاوت دارد از جابه‌جایی مستثناست و گوشهٔ قبلی‌اش
را حفظ می‌کند؛ همهٔ طراحی‌های پویای builder ممیزی بصری نشده‌اند.
آزمون واقعی same-document از Admin به سایت با primitiveهای سبک عمومی یکسان
و بدون runtime error گذشت؛ تزریق CSS پنل به صفحهٔ عمومی مشاهده نشد.

بازبینی مستقل فقط‌خواندنی یک تداخل selector در رنگ حذف taxonomy یافت؛ حذف از
accent مستثنا و رنگ danger خوانا صریح شد. ریسک header اختصاصی builder نیز
با استثنای بالا محدود شد. بازبینی منبع جای آزمون مرورگر را نگرفت.
موارد دیرترِ تبلیغ‌دهندگان/آمار، جدول UsagePanel، شمارندهٔ خطای AI، تب‌های
notification/support مینی‌اپ و خلاصه/یادداشت جزئیات بازی نیز در owner خود اصلاح
و دوباره در مرورگر بررسی شدند. هشدارهای Doctor در مجموع۱۱ فایل۰ خطا/۴۴ هشدار
بازبینی‌شده داشت؛ suppression یا تغییر وابستگی انجام نشد.

TypeScript UID1000 با incremental=false، source/import۳۰۰۹ فایل، architecture،
رجیستری افزونه و integrity دانش۱۴سندی گذشتند. Gitleaks نهاییِ redacted روی
