## Limits and next work

- These are ten public catalogue blocks, not arbitrary business queries, remote execution, a template/pattern/locking system or a replacement page builder. Only public projections are selectable; private content cannot be granted by inserting its ID. Arbitrary future parent-restricted/custom blocks require their own integration evidence.
- Five named portal settings are covered, alongside previous General/Forum history. Other owner forms need an actual field/secret/state audit before extension. Trusted context-less settings callers retain legacy behavior and do not automatically create an HTTP actor audit.
- History is not a way to rewind money, stock, ownership or credentials. Existing already-truncated historical documents cannot be reconstructed from the truncated row; restore now refuses them safely.
- Legacy CMS metadata paths outside the canonical block save were not universally made atomic in this batch. Broad domain maturity, production load, real provider delivery, deployment/backup/rollback evidence and full site WCAG remain outside this local result.
- Graphify refresh script is absent in this worktree; exact source/Serena discovery was used. No graph freshness or token-saving claim. No Storybook configuration exists here; actual component/browser states were exercised instead. No fresh production build/deployment was run.

Local raw reports/screenshots live in the ignored root `.mobocom/module-blocks-settings-evidence/`; private browser auth must be removed at cleanup. Portable native tests and this handoff are the committed continuation evidence.
