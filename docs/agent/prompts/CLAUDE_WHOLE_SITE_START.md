# Claude Code — شروع پروژه معماری یکپارچه موبوکام

در ریشه مخزن MoboComCMS این تسک را انجام بده:

`CLAUDE.md` و `AGENTS.md` موجود و راهنمای `docs/agent/WHOLE_SITE_EXECUTION_PROMPT.md` را بخوان. قراردادی که در `docs/agent/WHOLE_SITE_QUALITY_STANDARD.md` آمده باید کیفیت **کل سایت** را پوشش بدهد، نه فقط یک بخش. مرحله نخست تنها read-only audit + site IA + admin form/layout system + domain/extension map + evidence matrix + safe roadmap باشد. برای بخش‌ها ساختار تخصصی، فیلدها/روابط/گزینه‌های مدیریت‌پذیر و برای قالب‌ها و افزونه‌ها مدیریت امن شبیه وردپرس را طراحی کن. طبق تصمیم‌های موجود protected visuals/URLs/permissions/data را تغییر نده؛ هیچ migration/deploy/بازنویسی سراسری انجام نده. نتیجه را با path و شواهد واقعی و قدم اجرایی بعدی گزارش کن.

این متن تنها با درخواست صریح ممیزی سراسری اجرا می‌شود؛ نصب بسته به‌تنهایی آغاز این تسک نیست. از اسناد وضعیت موجود استفاده کن و شواهد قبلی را بدون اجرای جدید «تأیید مجدد» حساب نکن.
