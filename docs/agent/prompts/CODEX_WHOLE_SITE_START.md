# Codex — شروع پروژه معماری یکپارچه موبوکام

در ریشه مخزن MoboComCMS این تسک را انجام بده:

`AGENTS.md` و قوانین موجود + `docs/agent/WHOLE_SITE_EXECUTION_PROMPT.md` و `docs/agent/WHOLE_SITE_QUALITY_STANDARD.md` را به‌عنوان استاندارد معماری کل سایت اعمال کن. مطابق اجرای مرحله اول، ابتدا فقط Audit مستند، matrix واقعی همه بخش‌ها، blueprint چیدمان کل سایت و roadmap مرحله‌ای بساز. کیفیت کل Frontend/Backend/DB/API/Admin/Plugins/Themes/Security/Performance/SEO/RTL/A11y/Ops را پوشش بده. ساختار موجود را حفظ کن؛ refactor یا deploy گسترده نکن. مشکلات را با مسیر فایل و تست قابل‌اجرا نشان بده. در پایان نخستین vertical slice کم‌ریسک را با معیار پذیرش و rollback پیشنهاد کن.

این متن تنها با درخواست صریح ممیزی سراسری اجرا می‌شود؛ نصب بسته به‌تنهایی آغاز این تسک نیست. از اسناد وضعیت موجود استفاده کن و شواهد قبلی را بدون اجرای جدید «تأیید مجدد» حساب نکن.
