Options cannot provide an arbitrary directory through HTTP. Internal same-process contract uses typing + actual integration/HTTP checks per mobocom-contracts; no new independent/mobile/Pact contract.

Release rows use ID pages, directory names stream into a bounded sorted candidate page; file refs use grouped queries across all releases, not merely the current release page. Filename and release cursors/combined continuation, caps, checksum mode and observed counts are explicit. Stream traversal visits all flat directory entry names, so time is not bounded by page size; retained candidates/opened files are bounded. No recursion or cloud analysis. Invalid stored filenames are not opened or echoed. Root symlinks, nonregular/symlink files, read failures, inspection-size ceiling and replaced/changed files are uncertain observations. Checksums stream from a read-only handle; size-only results do not certify content. Inspector does not parse/approve package manifests or grant restoration authority. SQL and filesystem observations are not one snapshot. Source readers and operator documentation retain these limitations.
