# Network map data

`public/maps/world-110m.json` is a local, unmodified copy of `countries-110m.json` from **world-atlas 2.0.2**:

- Source: https://cdn.jsdelivr.net/npm/world-atlas@2.0.2/countries-110m.json
- Project: https://github.com/topojson/world-atlas
- Map data: Natural Earth 4.1.0, 1:110m Admin 0 country boundaries, redistributed as TopoJSON. Natural Earth data is public domain.
- Country borders are a coarse illustrative basemap. Location names and coordinates come from the application's published location records.
- The map is loaded from the application origin, with no third-party runtime request.
