# MoboCom 1.7.11

نسخهٔ پس از1.7.10، شامل تغییرات مرج‌شدهٔ PR380 و PR381.

- انتخاب مستقل API یا چت شخصی برای متن و تصویر هر دستهٔ تولید انبوه؛ حفظ بازبینی و ذخیرهٔ پیش‌نویس.
- پشتیبانی API رسمی Qwen و DeepSeek، درگاه OmniRoute و مدل‌های محلی Ollama.
- سرویس اختیاری «انتخاب خودکار کم‌هزینه»: اولویت منابع مجاز، محدودیت تلاش، ثبت خرابی و اعلان مدیر؛ بدون جایگزین پولی پنهان یا تکرار پاسخ نامطمئن.
- OpenRouter فقط با روتر مدل رایگان، Ollama با مدل نصب‌شدهٔ غیرابری، و OmniRoute با تأیید سیاست رایگانِ خود درگاه کار می‌کنند. کلیدهای مجاز خودتان لازم‌اند؛ کلید دیگران جمع‌آوری نمی‌شود.
- پل مرورگر شخصی۰.۴ با انتخاب چت متنی ChatGPT، Gemini، Qwen و DeepSeek؛ تصویر چت فعلاً فقط ChatGPT. رابط تازه، ورود و خطاها دقیق‌تر کنترل می‌شوند؛ سشن و کوکی به سرور منتقل نمی‌شود.
- workflowها مطابق درخواست مالک فقط دستی هستند؛ انتشار فایل به اجرای GitHub Actions نیاز ندارد.

## آپدیت

فایل **mobocom-1.7.11.mbrelease** را از Assets در **پنل سرور ← به‌روزرسانی امن** بارگذاری کنید. نسخه و ناشر قبلی را بررسی و بکاپ اجباری را تأیید کنید؛ ZIP سورس جای فایل آپدیت نیست.

نسبت به1.7.10 مهاجرت یا وابستگی تازه نداریم؛۱۷۷ مهاجرت قبلی و داده‌ها حفظ می‌شوند. بسته سورس امضاشده است؛ سرور بیلد Linux سازگار خودش را می‌سازد و RAM/swap/دیسک کافی لازم دارد. پس از نصب نسخهٔ پنل، ورود، ویرایشگر، رسانه و /api/health/ready را بررسی کنید.

همان افزونه را به۰.۴ ارتقا، دسترسی دامنه‌ها را بررسی، دوباره به موبوکام متصل و صفحه را تازه کنید. برای API به افزونه نیاز نیست. مرورگر چت هنگام تولید باید باز و در حساب خودتان وارد باشد. سازگاری حساب واقعی و رابط سرویس باید توسط اپراتور بررسی شود؛ چت وب و API رایگان تضمین نامحدود، سرعت یا دسترسی دائمی ندارند. هزینهٔ داخلی OmniRoute تابع تنظیم خود درگاه است.

تنظیمات قبلی خودکار به سیاست کم‌هزینه تبدیل نمی‌شوند. سیاست را صریحاً فعال و برای کاربرد یا دسته انتخاب کنید؛ مسیر دستیار مدیریت/Codex مستقل است. [راهنمای کم‌هزینه و اتصال‌ها](../AI-ECONOMY-FA.md) و [تولید انبوه](../AI-PRODUCTION-FA.md).

برای استفاده از Xray با میزبان‌های جدید Qwen/DeepSeek، ابزار root مربوط را مطابق راهنمای استقرار ارتقا و تنظیم را دوباره اعمال کنید؛ آپدیت وب ابزار مستقل میزبان را خودکار عوض نمی‌کند. درگاه محلی روی میزبان Docker با localhost کانتینر یکی نیست.

## بازگشت و شواهد

پیش از بازگشت، دسته‌های فعال را متوقف و سیاست کم‌هزینه را غیرفعال کنید. داده‌ها، رسانه و جدول‌ها حفظ شوند؛ بازگشت کد دیتابیس را به گذشته برنمی‌گرداند. بازیابی بکاپ تصمیم جداگانهٔ مالک است.

شواهد هدفمند PostgreSQL، نوع‌ها، امنیت و مرورگر قابلیت‌های PR380/381 در [تولید API](../agent/handoffs/AI_PRODUCTION_STANDARD.md) و [سیاست کم‌هزینه](../agent/handoffs/AI_ECONOMY.md) ثبت شده‌اند. حساب واقعی و سهمیهٔ مدل‌ها آزمایش نشده‌اند. نتیجهٔ بیلد دقیق بسته، امضا و دریافت دوبارهٔ فایل‌ها در یادداشت GitHub Release ثبت می‌شود؛ صرف تغییر شماره باعث تکرار مجموعه‌آزمون‌ها نمی‌شود.
