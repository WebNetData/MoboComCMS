# MoboCom 1.7.10

نسخهٔ پس از1.7.9، شامل تغییرات مرج‌شدهٔ PR377 و PR378.
شمارهٔ داخل بسته و پنل `1.7.10` است.

- اصلاح بارگذاری ویرایشگر متن و حفظ محتوای موجود.
- تولید انبوه۱ تا۵۰ مطلب مجله، محصول یا صفحه در
  **هوش مصنوعی ← تولید انبوه محتوا و تصویر** (`/admin/ai/production`).
- انتخاب دسته‌بندی، طول، لحن، کلمات کلیدی، دستور و اطلاعات قطعی؛ قیمت،
  موجودی، ارز، نوع و مشخصات محصول را مدیر مشخص می‌کند و مدل تغییر نمی‌دهد.
- تصویر شاخص و تا۳ تصویر داخل متن با سبک و نسبت دلخواه؛ ثبت فایل‌ها در
  کتابخانهٔ رسانه و سند استاندارد ویرایشگر همراه با توضیح تصویرسازی هوش مصنوعی.
- بازبینی، توقف، لغو، تلاش مجدد صریح و ادامهٔ نتایج ذخیره‌شده؛ ثبت نهایی
  تکراری محتوای تازه نمی‌سازد. مطلب/صفحه پیش‌نویس و محصول غیرفعال است؛
  انتشار با مدیر می‌ماند.
- پل مرورگر شخصی Chat وب نسخهٔ۰.۲ برای تولید متن و تصویر، جدا از دستیار
  Codex/مهندسی فعلی و بدون fallback به inference API یا Work.

## آپدیت از1.7.9

فایل **`mobocom-1.7.10.mbrelease`** را از Assets در
**پنل سرور ← به‌روزرسانی امن** بارگذاری کنید؛ نسخه و ناشر را بررسی و
پشتیبان‌گیری اجباری را تأیید کنید. کلید ناشر همان کلید قبلی است؛ ZIP سورس
و نصب‌کنندهٔ `.run` جای فایل آپدیت نیستند.

بسته سورس امضاشده است و بیلد Linux جداگانه روی سرور ساخته می‌شود؛ RAM،
swap، دیسک و دسترسی به وابستگی‌های قفل‌شده لازم است. سرور8GB شما همچنان
به مقدار مناسب `BUILD_MEMORY_MB` نیاز دارد. بعد از نصب نسخهٔ پنل، ورود،
رسانه، ویرایشگر و `/api/health/ready` را بررسی کنید.

یک مهاجرت افزایشی `20270224120000_ai_production` دو جدول دسته و ردیف
تولید را اضافه می‌کند؛ مسیر معمول `npm run deploy:migrate` آن را اجرا
می‌کند.۱۷۶ مهاجرت قبلی و داده‌ها دست‌نخورده‌اند. وابستگی جدید نداریم.

برای تولید، افزونهٔ پل را از صفحهٔ تولید دوباره دریافت و به۰.۲ ارتقا دهید،
دامنهٔ موبوکام را متصل و صفحه را تازه کنید. افزونه در مرورگر شخصی نصب
می‌شود؛ مرورگر و صفحه هنگام تولید باز بمانند. این قسمت به حساب واردشدهٔ
ChatGPT با حالت Chat و ابزار تصویر نیاز دارد. اتصال غیررسمی و وابسته به
رابط وب است؛ رایگان یا نامحدود بودن سهمیه تضمین نمی‌شود. ورود، CAPTCHA،
محدودیت حساب یا منع خواندن تصویر می‌تواند کار را متوقف کند. شکست خودکار
به API پولی منتقل نمی‌شود. کارکرد حساب واقعی شما باید توسط اپراتور بررسی
شود. [راهنمای تولید و محدودیت‌ها](../AI-PRODUCTION-FA.md).

تنظیمات و مسیر دستیار مدیریت/مهندسی و APIهای قبلی حفظ می‌شوند. اگر هنوز
ابزار مستقل root/worker مهندسی را از قبل ارتقا نداده‌اید، نیاز نسخهٔ قبلی
به پروتکل دانش۲ همچنان برقرار است؛ آپدیت وب ابزار میزبان را عوض نمی‌کند.

## بازگشت و شواهد

پیش از بازگشت کد تولید فعال را متوقف و پل را قطع کنید. جدول‌های افزوده،
پیش‌نویس‌ها و رسانه را نگه دارید؛ بازگشت کد دیتابیس را به گذشته برنمی‌گرداند.
بازیابی بکاپ تصمیم جداگانهٔ مالک است. [راهنمای بازیابی](../UPGRADE-FA.md).

هر سه بررسی الزامی PR378 شامل بیلد تولید و PostgreSQL/Redis موفق‌اند؛
شواهد قابلیت، مجوزها، ارتقای176→177، مرورگر و محدودیت حساب واقعی در
[handoff](../agent/handoffs/AI_PRODUCTION.md) ثبت شده‌اند و صرفاً برای تغییر
شماره تکرار نمی‌شوند. بیلد دقیق بسته، امضا، پذیرش ابزار نسخهٔ قبلی و سلامت
همان بیلد در رسید و یادداشت GitHub Release ثبت می‌شوند.
