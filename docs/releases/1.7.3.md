# MoboCom 1.7.3

این نسخه تغییرات مرج‌شده پس از `1.7.2` تا PR349 را بسته‌بندی می‌کند. بسته با همان ناشر نسخه‌های قبلی امضا شده است؛ کلید مورد اعتماد سرور عوض نمی‌شود.

## آپدیت سایتی که 1.7.2 یا قدیمی‌تر دارد (نصب Git)

آپدیت با اسکریپت‌های **نسخهٔ نصب‌شده** اجرا می‌شود و اصلاح‌های آپدیت‌کنندهٔ همین نسخه از آپدیت بعدی اثر دارند. برای همین یک بار، روی سرور:

۱. فایل‌هایی را که بیلد قبلی تغییر داده برگردانید؛ دستور آخر باید خروجی نداشته باشد:

    cd /opt/mobocom/app
    sudo -u mobocom -H git checkout -- next-env.d.ts tsconfig.json src/extensions/generated src/themes/generated src/themes/generated.css
    sudo -u mobocom -H git status --short

۲. اگر سرور به GitHub دسترسی پایدار دارد:

    sudo mobocom update 1.7.3

این مسیر بیلد را با ۴ گیگابایت حافظه اجرا می‌کند. جمع RAM و swap سرور دست‌کم ۶ گیگابایت باشد؛ بیلد روی سرور کوچک ۲۰ تا ۴۰ دقیقه طول می‌کشد.

۳. اگر GitHub کند یا مسدود است، با فایل `mobocom-1.7.3.bundle` (کنار این نسخه) بدون اینترنت آپدیت کنید:

    sha256sum /tmp/mobocom-1.7.3.bundle        # با mobocom-1.7.3.bundle.sha256 یکی باشد
    sudo chown mobocom: /tmp/mobocom-1.7.3.bundle
    sudo -u mobocom -H git -C /opt/mobocom/app remote set-url origin /tmp/mobocom-1.7.3.bundle
    sudo mobocom update 1.7.3
    sudo -u mobocom -H git -C /opt/mobocom/app remote set-url origin https://github.com/WebNetData/MoboComCMS.git

۴. پس از آپدیت، ابزار Xray سرور را یک بار تازه کنید تا چند پیکربندی و کاربردهای جدا فعال شود:

    sudo bash /opt/mobocom/app/deploy/ubuntu/xray-install.sh

از نسخهٔ 1.7.3 به بعد، دکمهٔ «به‌روزرسانی امن» پنل این کارها را خودش انجام می‌دهد: فایل‌های بیلد جلوی آپدیت را نمی‌گیرند، بیلد حافظهٔ کافی دارد و دریافت از GitHub زمان‌دار است و می‌تواند از پیکربندی Xray «به‌روزرسانی از GitHub» عبور کند.

**نصب بسته‌ای (پنل وب):** فایل **`mobocom-1.7.3.mbrelease`** را در **پنل سرور ← به‌روزرسانی امن** بارگذاری کنید. ZIP خودکار سورس فایل آپدیت نیست. نصب تازه: `mobocom-setup-1.7.3.run`.

## تغییرات

- **آپدیت مطمئن‌تر:** فایل‌هایی که خود بیلد بازنویسی می‌کند (`next-env.d.ts`، `tsconfig.json` و فایل‌های تولیدشدهٔ افزونه و پوسته) دیگر جلوی آپدیت و برگشت خودکار را نمی‌گیرند؛ یک نسخه از تفاوتشان در `storage/update` می‌ماند. آپدیت از پنل با ۴ گیگابایت حافظه بیلد می‌کند (`BUILD_MEMORY_MB`). دریافت از GitHub اگر یک دقیقه پیش نرود متوقف و یک بار با HTTP/1.1 تکرار می‌شود و با پیام روشن تمام می‌شود؛ `UPDATE_GIT_PROXY` اختیاری است.
- **پیوندهای یکتا بدون ریدایرکت:** لینک آهنگ و آلبوم در صفحهٔ خانه، صفحه‌سازها، منوها، صفحهٔ موزیک و اعلان‌ها مستقیم به نشانی نهایی (با نام خواننده) می‌رود.
- **کپچا و محافظت فرم‌ها:** کپچای داخلی بدون سرویس خارجی (و Turnstile به‌عنوان جایگزین) برای ورود، ثبت‌نام، بازیابی رمز، نظرها، نقد و پرسش، تالار، شبکهٔ اجتماعی، فرم‌ها و شروع گفت‌وگو؛ تنظیم در **مدیریت ← امنیت ورود**. راهنما: [کپچا و محافظت فرم‌ها](../HUMAN-CHECK-FA.md).
- **پروکسی Xray با چند پیکربندی:** در **پنل سرور ← پروکسی Xray** تا ۸ پیکربندی نام‌دار وارد کنید و برای تلگرام، اینستاگرام، به‌روزرسانی از GitHub و هوش مصنوعی جدا انتخاب کنید. پیکربندی قبلی خودکار «پیکربندی اول» تلگرام و اینستاگرام می‌شود.
- **موبوکام کلاد:** هاست، سرور، ابر و دامنه یک بخش شدند: صفحهٔ تازهٔ `/cloud` با کمترین قیمت هر خانواده، نوار مشترک روی `/hosting`، `/servers` و `/domains`، و نام «موبوکام کلاد» در پنل مدیریت و داشبورد کاربر. نشانی‌ها، دسترسی‌ها و داده‌ها تغییر نکرده‌اند.

## پس از آپدیت

- کپچای داخلی برای همهٔ بخش‌ها روشن است. اگر نمی‌خواهید، در **مدیریت ← امنیت ورود** خاموش یا سبک کنید.
- برای نمایش «موبوکام کلاد» در منوی بالای سایت، `/cloud` را از **مدیریت ← منوها** اضافه کنید.
- بخش موبوکام کلاد مثل قبل با ماژول «میزبانی» روشن یا خاموش می‌شود؛ آپدیت روشنش نمی‌کند.
