# MoboCom 1.7.4

نسخهٔ پایدار ۱.۷.۴ تغییرات `main` تا PR353 را شامل می‌شود. بسته با همان کلید ناشر قبلی امضا می‌شود؛ کلید مورد اعتماد سرور تغییر نمی‌کند.

## دریافت و آپدیت

- **از پنل وب:** فایل `mobocom-1.7.4.mbrelease` را از Assets همین انتشار دریافت و در **پنل سرور ← به‌روزرسانی امن** (`/admin/updates`) بارگذاری کنید. نسخه و ناشر را بررسی و پشتیبان‌گیری را تأیید کنید. ZIP خودکار سورس، فایل آپدیت نیست.
- **نصب Git:** `sudo mobocom update 1.7.4`. اگر GitHub روی سرور کند یا مسدود است، بستهٔ وب یا مسیر Git bundle پایین را استفاده کنید.
- **نصب تازه:** `sudo bash mobocom-setup-1.7.4.run`. برای آپدیت سایت نصب‌شده، نصب‌کننده را دوباره اجرا نکنید.

بیلد روی سرور انجام می‌شود؛ بستهٔ امضاشده، سورس قفل‌شده است و `.next` یا `node_modules` کامپیوتر ناشر را حمل نمی‌کند. مسیر پشتیبانی‌شده به ۴ گیگابایت heap بیلد، RAM/swap و فضای نسخهٔ جدا و بکاپ نیاز دارد. راهنمای کامل: [آپدیت و بازیابی](../UPGRADE-FA.md).

### نصب‌های Git با نسخهٔ 1.7.2 یا قدیمی‌تر

آپدیت با ابزارهای نسخهٔ نصب‌شده شروع می‌شود. اگر فقط فایل‌های بازنویسی‌شدهٔ بیلد جلوی آپدیت را گرفته‌اند، ابتدا `git diff` را بررسی و تغییرات واقعی خودتان را جدا نگه دارید؛ سپس همان فایل‌های تولیدی را برگردانید:

```bash
cd /opt/mobocom/app
sudo -u mobocom -H git checkout -- next-env.d.ts tsconfig.json src/extensions/generated src/themes/generated src/themes/generated.css
sudo -u mobocom -H git status --short
sudo mobocom update 1.7.4
```

برای دریافت آفلاین Git، bundle و checksum کنار همین نسخه را به `/tmp` سرور منتقل کنید:

```bash
sha256sum /tmp/mobocom-1.7.4.bundle
sudo chown mobocom: /tmp/mobocom-1.7.4.bundle
sudo -u mobocom -H git -C /opt/mobocom/app remote set-url origin /tmp/mobocom-1.7.4.bundle
sudo mobocom update 1.7.4
sudo -u mobocom -H git -C /opt/mobocom/app remote set-url origin https://github.com/WebNetData/MoboComCMS.git
```

checksum باید با `mobocom-1.7.4.bundle.sha256` یکی باشد. اگر هنوز ابزار Xray چندپیکربندی نسخهٔ 1.7.3 را روی میزبان نصب نکرده‌اید، بعد از آپدیت یک بار `sudo bash /opt/mobocom/app/deploy/ubuntu/xray-install.sh` را اجرا کنید.

## تغییرات این نسخه

- **انتخاب ویرایشگر برای هر مطلب و صفحه:** در فرم مقاله و صفحه می‌توانید ویرایشگر بلوکی یا کلاسیک را انتخاب کنید. مورد کلاسیکِ جدید متن را همان‌جا ذخیره می‌کند؛ مورد بلوکی به ویرایشگر بلوکی می‌رود. ویرایش مورد قدیمی با قالب ذخیره‌شدهٔ خودش آغاز می‌شود. متن بلوکی از فرم کلاسیک بازنویسی یا خودکار تبدیل نمی‌شود.
- **فورواردر خودکار لینک‌های خارجی:** در **مدیریت ← فورواردر و لینک کوتاه** گزینهٔ «اعمال خودکار روی همهٔ لینک‌های خارجی» اضافه شده و پیش‌فرض خاموش است. لینک‌های مطالب قبلی، جدید و بخش‌های پویا در مرورگر از صفحهٔ انتقال موجود عبور می‌کنند؛ با خاموش‌کردن، دوباره مستقیم می‌شوند. آدرس اصلی در محتوا حفظ می‌شود. لینک داخلی، پنل و محیط ویرایش تغییر نمی‌کند؛ مرورگر بدون JavaScript لینک اصلی را باز می‌کند.
- **ورود اطلاعات با مقدار دستی و دادهٔ موجود:** برای فیلدهای اصلی و تنوع محصول می‌توان مقدار ثابت یا نگاشت مقدارهای منبع تعیین کرد. دسته، برند، هنرمند و آلبوم از رکوردهای موجود انتخاب می‌شوند؛ انتخاب حذف‌شده یا تغییرکرده هنگام ذخیره دوباره بررسی می‌شود. کار جدید، ساخت خودکار رابطهٔ ناشناخته را بدون انتخاب صریح انجام نمی‌دهد؛ تنظیم کارهای ذخیره‌شده حفظ می‌شود. نامک‌های جدید از عنوان و مسیر منبع ساخته می‌شوند و امکان حذف نام برند منبع را دارند؛ آدرس رکوردهای قبلی تغییر نمی‌کند. [راهنمای ورود اطلاعات](../BULK_IMPORT.md).

اصلاح‌های سورس 1.7.3 هم در این بسته هستند: آپدیت‌کننده با حافظهٔ بیلد و دریافت زمان‌دار، پیوندهای نهایی آهنگ/آلبوم، کپچای داخلی و Turnstile، پروفایل‌های Xray و بخش موبوکام کلاد. [جزئیات 1.7.3](1.7.3.md).

## داده و بازگشت

نسبت به سورس 1.7.3، **migration تازه‌ای وجود ندارد**؛ ۱۷۰ migration قبلی تغییر نکرده‌اند. ارتقا از نسخهٔ قدیمی‌تر، migrationهای معوق خودش را هم اجرا می‌کند. محتوای بلوکی/کلاسیک، لینک‌های اصلی و تنظیمات قبلی حفظ می‌شوند. پیش از نصب بکاپ خارج از سرور داشته باشید؛ برگشت کد، دیتابیس را به گذشته برنمی‌گرداند.

پس از آپدیت، نسخهٔ پنل، ورود، یک مقاله/صفحهٔ قدیمی، انتخاب دو ویرایشگر و روشن/خاموش‌کردن فورواردر را بررسی کنید. نتایج دقیق بررسی‌های ناشر در [گزارش انتشار](../agent/handoffs/RELEASE_1_7_4.md) ثبت می‌شود؛ آزمون محلی جای تأیید روی سرور شما را نمی‌گیرد.
