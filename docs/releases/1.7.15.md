# MoboCom 1.7.15

این نسخه تغییرات مرج‌شدهٔ پس از ۱.۷.۱۴ (PR405 تا PR413) را یکجا ارائه می‌کند.

- **تأیید پیامکی اجباری موبایل:** در **مدیریت ← فیلدهای ثبت‌نام**، فیلد «شمارهٔ موبایل تأییدشده» را فعال و ضروری کنید. هر کاربری که با ایمیل، تلگرام یا راه دیگری وارد شده باشد، تا تأیید شماره با کد پیامکی به صفحهٔ تکمیل مشخصات هدایت می‌شود. این مرحله شش خانهٔ جدا برای کد دارد و پرشدن خودکار از پیامک را پشتیبانی می‌کند. این فیلد پس از آپدیت خاموش است و تا وقتی ارسال پیامک تنظیم نشده باشد، از کاربر خواسته نمی‌شود. ورود با تلگرام هم حالا مثل ورود عادی، تکمیل مشخصات را بررسی می‌کند.
- **قالب یکپارچهٔ ایمیل‌ها:** ایمیل‌های اطلاع‌رسانی، امنیت حساب، کد ورود، خبرنامه و کارت هدیه قالب مشترک دارند. این قالب شامل سربرگ برند، کد درشت و قابل‌کپی، دکمه‌های مطمئن، حالت تیره، چیدمان موبایل و فونت وزیرمتن است. افکت‌ها فقط در برنامه‌هایی که پشتیبانی می‌کنند دیده می‌شوند.
- **فروشگاه:** فروشگاه فایل طراحی‌شده داخل فروشگاه، رسانهٔ مرتب برای هر کالا، سود جداگانه برای گونه‌های ارزی، انتخاب زمان انتشار و تکمیل فیلدهای کالا با هوش مصنوعی.
- **نام بخش‌ها از مدیریت:** نام هر بخش در همهٔ سایت از مدیریت تعیین می‌شود. بخش‌های تغییرنام‌یافته نام و نشانی خود را دنبال می‌کنند. میز انتشار خودکار در شبکه‌های اجتماعی بازطراحی شده است.
- **محتوا:** پنج سبک تمام‌صفحه برای مقاله، چهار قالب برای فرم‌ها، و تصاویر مرتب با تکمیل هوش مصنوعی در همهٔ بخش‌ها.
- **Next.js 16.4.6** به‌جای 16.4.2. React و TypeScript تغییر نکرده‌اند.

## آپدیت

فایل **mobocom-1.7.15.mbrelease** را در **پنل سرور ← به‌روزرسانی امن** بارگذاری کنید، یا روی سرور `sudo mobocom update` را اجرا کنید. ناشر باید همان ناشر قبلی باشد و بکاپ اجباری است. ZIP سورس فایل آپدیت نیست؛ بستهٔ امضاشده روی سرور Linux بیلد می‌شود. برای سرور ۸ گیگابایتی، RAM آزاد، swap و `BUILD_MEMORY_MB` را بررسی کنید.

یک مهاجرت تازه دارید: `20270228120000_variant_fx_markup`. این مهاجرت دو ستون اختیاری سود به گونه‌های کالا اضافه می‌کند. مقدار خالی یعنی همان سود کالا، و دادهٔ موجود تغییر نمی‌کند.

## بررسی و بازگشت

پس از آپدیت این موارد را بررسی کنید: نسخهٔ پنل، `/api/health/ready`، ورود، صفحهٔ تکمیل مشخصات، فروشگاه و ارسال یک ایمیل آزمایشی. پیش از روشن‌کردن تأیید اجباری موبایل، ارسال پیامک را آزمایش کنید.

بازگشت کد، ستون‌های تازه و تنظیمات را نگه می‌دارد. بازگردانی دیتابیس تصمیم جداگانهٔ مالک است. نسخه‌ها و فایل‌های منتشرشدهٔ قبلی بازنویسی نمی‌شوند.

بررسی‌ها، تست‌ها و بیلد production روی GitHub اجرا شده‌اند و نتیجهٔ واقعی آن‌ها در توضیح PR انتشار ثبت شده است. امضای بسته روی کامپیوتر ناشر انجام می‌شود و کلید خصوصی به GitHub نمی‌رود.
