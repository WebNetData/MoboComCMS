# MoboCom 1.7.12

شامل اصلاح مرج‌شدهٔ [PR383](https://github.com/WebNetData/MoboComCMS/pull/383) پس از1.7.11.

- رفع ماندن تولید انبوه روی «نوشتن متن» وقتی نشان پایان در بخش دیگری از پاسخ Chat نمایش داده می‌شود.
- بازیابی پاسخ همان مرحله به‌جای ارسال دوبارهٔ درخواست نامطمئن؛ نگهداری موقت نتیجه و دکمهٔ جداگانهٔ گفتگوی تازه با هشدار تکرار مصرف.
- یک گفتگوی اختصاصی برای هر مطلب: ابتدا متن، سپس درخواست جداگانهٔ تصویر شاخص و هر تصویر داخلی؛ تصاویر ردیف‌های دیگر انتخاب نمی‌شوند.
- حفظ متن نامرتبط کادر Chat، خروجی ذخیره‌شده، تصاویر قبلی و بازبینی پیش‌نویس؛ مسیر دستیار مدیریت/Codex و API استاندارد مستقل می‌ماند.

## آپدیت

فایل **mobocom-1.7.12.mbrelease** را در **پنل سرور ← به‌روزرسانی امن** بارگذاری کنید؛ ناشر قبلی و بکاپ اجباری را بررسی کنید. بسته سورس امضاشده است و سرور بیلد Linux خودش را می‌سازد؛ ZIP سورس و فایل .next جای بسته نیستند.

نسبت به1.7.11 مهاجرت یا وابستگی جدید نداریم؛۱۷۷ مهاجرت و داده‌ها حفظ می‌شوند. پس از آپدیت نسخهٔ پنل، ورود، ویرایشگر، رسانه و /api/health/ready را بررسی کنید.

**پل مرورگر را به۰.۵ ارتقا دهید:** تولید فعال را متوقف، فایل‌های همان افزونه را جایگزین، در chrome://extensions یا edge://extensions گزینهٔ Reload را بزنید، دوباره به سایت متصل و پنل را تازه کنید. فقط تعویض فایل‌ها کافی نیست. بازیابی فقط برای درخواست‌های ثبت‌شدهٔ نسخهٔ جدید، همان تب پنل/گفتگو و session مرورگر، حداکثر۲۰ دقیقه است؛ گفتگوهای قدیمی۰.۴ خودکار وارد نمی‌شوند. بستن تب یا مرورگر ممکن است نتیجهٔ موقت را پاک کند.

برای ادامه ابتدا «ادامه و بازیابی همین مرحله» را انتخاب کنید؛ «گفتگوی تازه» ممکن است تولید و مصرف را تکرار کند. برای API استاندارد افزونه لازم نیست. چت شخصی تضمین رایگان/نامحدود ندارد؛ حساب واقعی، ابزار تصویر و امکان خواندن پیکسل تابع سرویس و CORS مرورگر هستند. مسیر مخفی، استخراج کوکی یا API پولی جایگزین وجود ندارد.

## بازگشت و شواهد

پیش از بازگشت کد یا افزونه، تولید را متوقف کنید. داده‌ها و تصاویر ذخیره‌شده حذف نمی‌شوند؛ بازگشت کد دیتابیس را به گذشته برنمی‌گرداند. بازیابی بکاپ تصمیم جداگانهٔ مالک است.

شواهد مرتبط [اصلاح Chat](../agent/handoffs/AI_CHAT_RECOVERY.md): بازتولید باگ۰.۴، افزونهٔ واقعی با پاسخ کنترل‌شده، بازیابی بدون ارسال تکراری، جریان دو مطلب با متن و چهار تصویر، پنل واقعی با PostgreSQL و API کنترل‌شده، چهار نمای موبایل/دسکتاپ و دسترس‌پذیری، نوع‌ها و بررسی‌های امنیتی. حساب واقعی ChatGPT آزمایش نشده است. نتیجهٔ بیلد دقیق بسته، امضا و دریافت دوبارهٔ فایل‌ها در GitHub Release ثبت می‌شود؛ مجموعه‌آزمون‌های قبلی تکرار نمی‌شوند.
