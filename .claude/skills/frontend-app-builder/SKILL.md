# Frontend App Builder for MoboCom

For a new visual surface, capture the workflow, required content, constraints and responsive states in a compact design brief. Use a maintained Figma reference or an approved wireframe. Use image generation only where a legitimate visual asset or concept adds value. Keep functional copy, data and interactive controls native to the application. Implement reusable parts through the existing SDS owners. In the real browser, compare the complete primary flow and representative responsive states with the brief or approved reference. Repair measurable mismatches and report unresolved ones.

This scoped adaptation uses the MoboCom browser gate and respects existing architecture. Upstream Build Web Apps 0.1.2 declares MIT in its manifest. This edition summarizes its concept and comparison workflow, without enabling the full plugin or its payment, database, registry or provider guidance.
