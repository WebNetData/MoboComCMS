# Taste Skill for MoboCom

Choose the visual focus from the user task and approved identity. Read the actual copy, typography, spacing and imagery as a whole at a normal viewing size. Align edges and repeated elements deliberately. Give high-value actions a clear position and reduce decorative copy or repeated treatment that obscures them. Use approved real imagery when it adds meaning. For a new composition, compare sections for hierarchy, pacing and a coherent graphic language. Review responsive crops and reflow in the existing browser workflow.

Use the existing type, density, theme and motion rules. Select this or another art direction companion for the pass. This text adaptation excludes upstream checker scripts, the Stop hook, effects/assets, remote fetches and mandatory full-screen sections or motion.
