# Impeccable manual critique for MoboCom

Use the upstream manual fallback with the checked-in design and real browser output. Name the screen and the user's next decision. Look for a weak hierarchy, ambiguous action or state, inconsistent detail, and failure under constrained widths, long text or keyboard use. Pick a small set of evidenced issues. Give each a location, user impact and proposed adjustment. For authorized implementation, fix the relevant problems and verify the same states again. For review, report the findings without editing.

Use the MoboCom visual quality gate and existing browser tools. This modified edition does not install or invoke the launcher, automatic detector, scoring engine, shortcuts, hooks or downloads. The original project notices are retained.
